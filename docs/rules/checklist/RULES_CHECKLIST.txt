블러드본 규칙 구현 점검표 v0.8.1
기준: 2026-10-12 KST
한 명의 사냥꾼으로 기나긴 사냥 챕터 1~3. 제공 장치무기15종 양면·화기8종·실제 보스/NPC·보상32종(사용 효과30종·사용불가 임무 물품2종). 다른 캠페인과 다인/온라인 협동은 사용자가 이후 단계로 지정하여 이번 완료 범위에서 제외한다.

구현 상태·검증 근거·사용자 직접 점검은 별개입니다. 114항목의 직접 점검은 모두 미점검입니다.
정규 범위110항목: 구현106,범위제외4,부분0,미구현0. T01은 검증 도구, U01~U03은 UI 개선 단계입니다. 전체 UI 재설계 완료를 뜻하지 않습니다.

status는 구현 여부, verification은 근거 수준, manualCheck는 사용자의 직접 점검 결과입니다. 서로 같은 의미가 아닙니다.
manualCheck는 모두 미점검으로 시작합니다. 자동 테스트가 존재해도 사용자의 직접 확인을 완료로 표시하지 않습니다.
자동 테스트 근거 있음은 테스트명/파일이 존재한다는 의미입니다. 최종 버전 실행 결과는 VERIFICATION.txt를 확인합니다.
부분·미구현·범위 제외가 섞인 이 목록으로 전체 규칙 완성률/100%를 계산하지 않습니다.
페이지1/3/11/28은 표지·목차·준비 안내·제작진 페이지여서 독립 실행 조건 행으로 만들지 않았습니다. 22쪽 전투 예시는 전투 행의 근거에 포함합니다.
기존 실행16종에 추가 효과14종을 연결했습니다. 작은 오르골·의식용 재료2종은 원문 사용불가 임무 물품으로 등록하며 임의 효과를 만들지 않습니다.
후속 임무 테스트에는 유효 상태를 조립한 분기/경계 검증도 있습니다. 실제 새 사냥부터의 전체 명령 완주 근거는 별도 행/VERIFICATION.txt로 구분합니다.
보스 초기화의 일반 위치 보존, 챕터2 카드20/22의 지정칸 재출현, 챕터3 카드42의 위치 보존은 서로 다른 조건입니다.
새 v0.7.7 사냥은 rulesVersion13의 호위 먼저 재정을 사용한다. 규칙12 이하 저장은 가져오기 시 당시 상태를 정확히 복원한 뒤 APPLY_CHAPEL_RULING 일회 명령으로 새 재정을 채택한다. 아직 결정하지 않은 동시 도착은 호위를 먼저 완료하며, 이미 완료된 56 분기와 보상은 보존한다. 저장 형식과 v07 키는 유지한다.
장치무기 시트의 아랫줄은 반대 면 요약입니다. 현재 면의 두 번째 능력으로 적용하지 않습니다.
새 실물 적12종은 독립 연습에서 선택합니다. 기나긴 사냥의 임무에서 요구하는 기존 적 구성은 해당 임무 지시를 유지합니다.
규칙10의 실제 구성품으로 장송의 칼날·기본 단총 한 경로를325개 공개 명령만으로 진행하여 챕터1~3 연속 승리와 정확 저장 재생을 검증했습니다. 실제 성직자 야수는 챕터2/3의 체력10/8·양 페이즈 행동 덱을 사용하며 최종 꿈에서 사냥 트랙은 늘지 않습니다. 모든 무기 조합·모든 곁가지 경로의 본편 완주를 검증한 것은 아닙니다.
연습 시작 보상은 정규 임무 획득 보상이 아닙니다. 선택 수량을 초기 저장 설정에 기록하며 도구·문자 각각2장과 인쇄 공급량을 적용합니다.
무기15종×시작 면2×화기8종의240조합은 v0.7.5에서 검증한 규칙12와 보존 규칙10·11에서 각각 공개 명령 전투 연습·준비·변형·꿈·귀환·저장을 검사한다(총720개 전투 행렬). 모든 조합의 본편 완주를 뜻하지 않는다. 현재 기본 규칙13의 최종 실행 범위와 수는 VERIFICATION.txt에서 확인한다.
v0.7.7는 한 캠페인의 1인 플레이를 완료 기준으로 삼는다. 다른 캠페인과 다인 실행은 남은 필수 작업으로 계산하지 않는다.
공개 명령으로 실제 처음부터 도달한 임무 곁가지와 무기별 본편 승리의 범위는 C01~C10 및 VERIFICATION.txt에서 확인한다.
같은 예배당 이동 종료에서 37 호위가 완료되면 39를 먼저 획득하고 그 결과를 반영하여 56을 판정한다. 사용자 결정으로 채택한 프로젝트 재정이며 공식 FAQ의 고유 판정으로 표시하지 않는다. 플레이어에게 순서 선택이나 아직 공개하지 않은 목표·보상·분기 비교를 보여주지 않는다. 호위가 없는 도착은 56의 일반 조건을 유지한다.
v0.7.3 이전 기록에 적힌 한 승리 경로와 단순 정책의30패배는 당시 검증 범위다. 최신 자연 승리 결과는 VERIFICATION.txt를 기준으로 한다.

v0.7.4에서는51/52의 자연 진입만 확인하고 정상 완료 경로는 미확보였다. v0.7.5에서는 원문 조건과 기본 시작 지급을 유지한 공개 명령만으로51의343명령 연구 완료/26/수혈액 장착·사용(체력3·트랙8),52의384명령 새 생존자2개 인도/28/사자 선물 장착(체력6·트랙8)을 추가 확인했다. 해당 임무 완료 기록 자체의 챕터3 최종 보스 승리를 주장하지 않는다.
실제 과거 저장39개와 독립 v0.7.0 111·v0.7.1 277·v0.7.2 326·v0.7.3 326·v0.7.4 326개를 합한1405개가 정확 복원됐다. 최종 실제 검사 수는 VERIFICATION.txt를 확인한다.
T01은 검증용 장비·시작 지급·소모품·별도 자동 저장을 다루는 개발 도구이다. 테스트 전용 장비로 진행한 결과는 정규 규칙의 난이도·정상 완주 근거로 계산하지 않는다. 정규 데이터의15무기·36소모품 공급과 정규 자동 저장은 유지한다.
U01은 원본 사진 제거와 텍스트 읽기, U02는 지도 중심 HUD와 보조 정보 패널, U03은 지도 대상 직접 선택·공개 비용 표시와 표시 엔진의 첫 연결이다. 전체 전투·이야기 연출과 정식 시각 자산 제작이 끝났다는 뜻은 아니다. 엔진 규칙13과 정규 캠페인의 실행 범위는 유지한다.
U02의 정보 패널 열기·전환·닫기와 초점 복원은 표시 동작이며 게임 명령이나 저장 상태를 바꾸지 않는다. 패널 안의 실제 소모품·보상 사용은 기존 명령을 실행한다. 화면 크기별 브라우저 결과는 VERIFICATION_v080.txt의 실제 확인 범위로 기록하며 모든 내용을 스크롤 없이 표시한다고 일반화하지 않는다.
U03의 대상 선택·비용 확인·선택 취소는 게임 명령을 실행하지 않는다. 이동·탐험 실행은 기존 MOVE 다음 STEP/EXPLORE 명령을 사용하고 추가 카드 비용을 만들지 않는다. 보스 정보에는 현재 전투에서 실제로 공개한 행동만 표시한다. Phaser 4.2.1은 공개 좌표와 실제 처리된 행동의 표시만 담당하며 저장과 규칙을 계산하지 않는다. 테스트 파일 존재와 최종 실행 결과를 구분하여 VERIFICATION_v081.txt를 확인한다.
