## 로컬 및 클라우드 경계

최초 클라우드 작업은 연결 GitHub API로 커밋과 이 문서를 읽었으나, 클라우드 셸의 Git 인증은 실패했습니다. 파일별 소스 재구성 도중 시스템 오류로 작업이 중단되어, `.github/workflows/cloud-handoff.yml`에서 **Git에 커밋한 파일만** 비공개 GitHub Actions artifact `bloodborne-cloud-source`로 전달합니다. 이 artifact는1일 뒤 만료되며 인증·개인 저장·ignored 원본 사진이 포함되지 않습니다. GitHub 연결의 workflow artifact 다운로드로 원본 ZIP을 가져오고 내부 tar.gz의 SHA-256과 commit 파일을 대조해 같은 소스를 확보합니다. 파일마다 대량 텍스트를 다시 가져오는 방식으로 같은 중단을 반복하지 않습니다.

이전 로컬 서버와 사용자 브라우저는 PC가 종료되면 사용할 수 없습니다. 실제 테스트베드의 원본 저장 파일은 로컬 작업 폴더에만 있고 개인 저장은 올리지 않았습니다. audit의 생성기·초기 옵션·정상 명령으로 새로운 QA 시작점을 재생성합니다. 연결된 GitHub의 비공개 저장소에 클라우드 작업이 접근 가능한지 확인해야 합니다. 클라우드 대화를 만들기만 하고 저장소 접근·실행을 확인하지 않은 상태를 '컴퓨터를 꺼도 계속 작업 중'이라고 보고하지 않습니다.
