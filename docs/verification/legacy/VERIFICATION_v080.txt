소모품·보상·일지·적 정보·도움말/저장은 정보 창으로 옮겼습니다.
현재 공개된 목표 전체는 일지에서 확인하며 고정 화면에는 주요 진행 목표를 표시합니다.
지도 적 토큰 클릭으로 대상을 선택하고 현재 위치 버튼으로 지도를 맞춥니다.

닫기/Escape·창 전환의 포커스 복원·읽기와 저장 분리·행동 오류 표시를 연결했습니다.

자동 검사
전체58개파일의1,911개 검사를 실행했습니다: 처음1,902개통과,9개실패(약315초).
9개는 모두 고정 목표 영역에 곁가지 목표 전체가 있다고 가정한 이전 표시 계약이었습니다.
실제 일지를 열어 공개된 목표 전체를 검사하도록 해당 테스트를 갱신했습니다.
미공개 목표·보상·분기 차단, 정상 명령 경로, 저장 보존 검사는 유지했고 제목도 보존했습니다.
그 후 최종 UI 재검사92/92통과, 실패/건너뜀0(약66초). 작은 배치 보정 후 기존 전체검사는 반복하지 않았습니다.
전체 실행과 최종 UI 재검사를 합쳐1,911개기존/추가항목을 확인했고 미해결 실패는0입니다.
신규HUD10개검사는 실제 정상 규칙13·무기의351개공개UI명령으로 챕터1~3완주와 매 단계 저장 복원을 포함합니다.
QA 소모품 사용·실제 전투 중 유골 사용·필수 보상 선택·정보창/이야기/Escape/포커스 복원을 확인했습니다.
새 사냥 설정에서 정보창이 남아 있던 문제와 패널의 초기 문법 오류를 수정했습니다.

실제 브라우저
별도127.0.0.1:8780에서 정상 공개 명령으로 생성한 검증 저장들을 불러와 검사했습니다.
개발용 장면 선택기는 배포본에 포함하지 않습니다. 사용 중인8769 진행 저장은 덮어쓰지 않았습니다.
1366×768: 페이지 높이768, 상태·목표·지도·손패·무기·행동이 뷰포트 안에 있습니다.
1280×720: 타일 배치·적 이동·전투 대응에서 페이지720, 행동 영역236/내용236으로 내부 스크롤이 필요하지 않았습니다.
1366×768손패6장: 손패영역528×134,내용동일528×134,6장모두영역안2줄표시.
일반 조우·전투 대응·보스 대응·필수 보상 선택도 한 화면에서 주 행동을 확인했습니다.
1920×1080과414×896에서도 페이지가 뷰포트 크기를 넘지 않으며 현재 전투 버튼을 확인했습니다.
긴 이야기/정보와 챕터 준비의 내부 스크롤, 큰 지도 탐색을 위한 지도 이동은 허용합니다.
좁은 화면의 자세한 가독성·조작감은 수동 플레이 점검이 남아 있습니다.
브라우저 파일 선택기 대기가 길어 이후 검증은 격리된 개발용 장면 선택기로 정상 저장을 검증하며 진행했습니다.
