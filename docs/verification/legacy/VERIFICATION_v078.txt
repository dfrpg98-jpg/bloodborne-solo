기나긴 사냥 싱글 — v0.7.8 검증 기록
작성일: 2026-10-12

변경
- 정규 장치무기 목록과 분리한 검증용 장치무기: 속도 3, 양면 피해 12/6.
- 검증용 회복약, 슬롯 비우기·손패 보충, 카드 비용 없는 6칸 이동.
- 빠른 기본 지급과 직접 고르는 시작 보상·소모품. 챕터마다 선택한 소모품 재준비.
- 일반/검증 자동저장과 이어하기를 분리하고, 화면·내보내기 파일에 검증 표기.
- QA 시작 보상은 별도 지급본으로 표시하여 임무 보상의 정규 공급을 보존.
- 독립 보상 모듈 상태에 setup이 없을 때의 정상 보상 처리 회귀를 수정.

자동 검사
전체 56개 파일, 1,893개 검사를 실행했습니다. 처음에는 1,867개 통과,
독립 보상 테스트 26개가 동일한 QA 초기 상태 접근 문제로 실패했습니다.
문제를 수정한 뒤 두 보상 파일과 두 QA 파일을 다시 실행하여 52/52 통과했습니다.
처음 실패했던 26개를 모두 다시 확인했고 남은 실패는 0개입니다.
수정은 보상 모듈의 setup 없는 상태에 대한 안전 접근 세 곳입니다.
수정 후 전체 5분 회귀를 반복한 것은 아니며, 위 결과는 전체 실행과 영향 범위 재검사의 합입니다.

QA 추가 검사 16개에는 다음을 포함합니다.
- QA 장비·지급의 정상 공급 분리, 유효 입력과 잘못된 입력 거절.
- 실제 적 첫 처치, 손패 보충, 실제 피해 후 회복·화기 준비, 정확한 저장 복원.
- 정규 무기를 사용하는 QA 경로의 공개 명령 320개로 챕터 1→2→3 완주.
- 두 차례 챕터 전환에서 QA 소모품 재지급, 실제 임무 보상과 QA 시작 보상 공존.
- 화면에서 QA 시작·소모품 사용·6칸 이동·불러오기·일반/QA 이어하기 저장 분리.

기존 정규 검사는 15종 무기의 챕터 1~3 완주, 양면×8화기 240조합 전투,
60장 임무의 정상 공개 경로와 108개 분기 조건 검사를 포함하여 통과했습니다.
240조합을 각각 최종 보스까지 완주했거나 가능한 모든 분기를 완주했다는 뜻은 아닙니다.

실제 브라우저
별도 localhost:8778에서 검증 모드를 시작하여 v0.7.8 표기, 검증 무기,
소모품 6장, 시작 보상 4장과 별도 저장 안내를 확인하고 화면을 기록했습니다.
사용 중인 localhost:8769의 진행 저장을 검증 플레이로 덮어쓰지 않았습니다.

속도 비교
seed 1의 같은 첫 야수 처치 사례: 일반 25명령, 검증 10명령.
임무별 경로와 준비 상태에 따라 차이가 달라지므로 전체 작업의 일정 배속을 보장하지 않습니다.
정규 120명령 저장 복원 비교: 마지막 한 번 약 114ms, 매 단계 복원 약 2629ms.
평상시 QA는 임무·챕터·중단/재개 지점과 최종 저장을 확인하며,
저장 관련 결함을 조사할 때는 매 단계 재생 검사도 유지합니다.
검증 도구로 승리한 기록은 정규 무기 성능이나 정규 완주의 증명과 별도로 취급합니다.

구현 현황
정규 범위 점검표 110항목: 구현 106, 범위 제외 4, 미구현·부분 구현 0.
개발 도구 T01을 추가한 점검표는 111행입니다.
현재 기나긴 사냥의 싱글 챕터 1~3을 진행할 필수 기능과 제공 자료 반영은 완료했습니다.
추가로 필요한 필수 자료 요청은 없습니다.
사용자가 직접 체감과 예상 밖 플레이 상황을 확인하는 수동 점검란은 미점검으로 남겨 두었습니다.
본문 전체 텍스트화와 타일 배경 그림은 선택적인 가독성·연출 개선입니다.
다른 캠페인과 멀티플레이는 사용자의 후속 요청 때 진행합니다.

설치·배포 파일의 SHA-256 대조 결과는 설치 후 기록에 덧붙입니다.
