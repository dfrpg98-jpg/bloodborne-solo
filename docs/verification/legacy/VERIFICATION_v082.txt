Phaser 4.2.1 및 그림 5종의 로딩, canvas/client box 일치, 실제 한 칸 이동, 판정 완료 후 양측 공격 2회, 화기 발사를 확인했습니다.

1280×720, 1366×768, 1920×1080, 414×896에서 탐험/전투 8장면을 확인했습니다. page/client/canvas 크기가 실제로 반영된 최종 browser 기록을 기준으로 하며 각 장면에서 페이지와 행동 영역의 불필요한 스크롤이 없고 줌 버튼이 표시되었습니다. 작은 화면의 실제 터치 조작감은 별도 사용자 점검 대상입니다.
일반 표시 장면과 5개 인물 유형의 검증에서 콘솔 오류는 없었습니다. 모든 전투/적 조합의 미술적 품질이나 모든 프레임의 이상 없음까지 자동 검사로 인증하지 않습니다.
file:// 직접 실행 브라우저 검사는 도구 URL 정책이 http/https만 허용해 수행하지 못했습니다. 인라인 atlas/native Image 로더로 JSON XHR을 제거했지만 실제 브라우저 실행 확인은 localhost에 한정됩니다.
