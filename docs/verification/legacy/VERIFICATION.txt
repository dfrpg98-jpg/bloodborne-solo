진료소 자동 분기는 실제 처리한 결과만 보여 줍니다. 진료소 상호작용의 피해·기술 뽑기 의미를 그대로 유지합니다.

원본 외형과 동작
장치무기 30개 외형의 실제 원본과 런타임 PNG를 독립 비교했습니다. 28개는 제공 사진의 인물 크롭, 장송의 칼날 2개는 실제 게임 영상 캡처입니다. 모두 정지 자세이며 원작 공격 콤보 확보로 세지 않습니다.
적 6종·행동 구성 11개의 원본 RGB와 SHA를 독립 대조했습니다. 새로 그린 몸·무기·가려진 팔다리를 추가하지 않았습니다.
야수 사냥 무리는 원작의 복장·무기가 다른 개체들을 같은 종류의 변종으로 검토합니다. 도끼·횃불 개체에 원본 이동 구간 4프레임(320ms)을 연결했습니다. 완전한 보행 주기나 도끼 공격 완료 모션이 아닙니다.
여성 야수 환자는 500×729 원본 전신 크롭으로 교체하고 발톱·망토 주름·옷자락·노출된 발끝을 독립 검토했습니다. 경계가 불확실한 붙잡기 영상은 사용하지 않았습니다.
성직자 야수 2페이즈는 같은 원작 모델 자료의 다른 시점 이미지를 사용합니다. 두 페이즈의 몸 크기·발 위치를 맞추고 이미 공개된 페이즈에 따라 전환합니다. 원작의 별도 변신 모델이나 연속 변신 모션을 확보한 것은 아닙니다.
적 행동 36개에는 실제 공개된 판정의 표시 효과를 연결했습니다. 원작의 준비·타격·회수까지 이어지는 공격 동작은 별도 확보가 남았습니다.

보존과 배포
참고자료의 원본은 수정하지 않습니다. 차단된 원본 다운로드는 중단하며, 필요한 링크를 사용자에게 전달합니다.
배포 ZIP에서 참고자료·원본 임무 사진·개발용 장면 불러오기 화면을 제외합니다. 게임용 원본 인물 크롭과 로컬 표시 엔진은 포함합니다.
설치 시 기존 프로젝트 전체를 먼저 백업하고, 기존 파일 충돌·새 자료 변동·복사 후 모든 배포 파일의 SHA를 확인합니다. 실제 백업·복사 수량은 별도 설치 결과에 기록합니다.
