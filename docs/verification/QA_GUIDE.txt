기나긴 사냥 검증 도구 · v0.7.8

시작 방법
게임 화면에서 ‘새 사냥’ → 플레이 모드 ‘기나긴 사냥 · 검증 전용’을 선택합니다.
검증용 장치무기와 ‘빠른 임무 검증’ 프리셋을 선택하고 시작 칸을 정해 시작합니다.
‘시작 보상·소모품 직접 선택’에서는 정규 무기로 시작하면서 필요한 보상·소모품만 지급할 수도 있습니다.

검증 전용 장치무기
양면 각각 슬롯3개, 속도3. 앞면은 피해12, 뒷면은 피해6.
높은 피해로 전투에 필요한 명령을 줄입니다. 적의 무적·방어·속도·보스 페이즈 전환·임무 처치 조건은 기존 절차로 처리합니다.

검증 소모품
회복약: 체력6치유, 화기준비.
손패 보충: 모든 공격 슬롯을 비우고 카드3장뽑기.
이동: 스탯 카드 없이 최대6칸이동. 탐험·추격·안개·이동종료 임무를 정상 처리합니다.
프리셋은 각2장씩 총6장을 준비합니다. 챕터가 바뀌면 지정한 검증 소모품을 다시 준비합니다.
직접 선택 시 각 검증 소모품10장까지, 전체 소모품40장까지 선택합니다. 정규 소모품은 실제 덱의 수량 안에서 가져옵니다.

시작 보상
빠른 프리셋: 랜턴·고대 사냥꾼의 유골·사냥 문자·오에돈 문자.
직접 선택 시 등록된 보상을 각 카드의 구성 수량 안에서 총16장까지 지급합니다.
검증 시작 보상은 qaStart로 표시한 별도 지급본이며, 이후 임무가 지급할 정규 보상의 공급을 소진하지 않습니다. 시작 지급은 한 번이며 챕터 간 보존합니다.
도구·문자의 장착 한도와 보상 선택 절차는 그대로 적용됩니다. 지급을 많이 선택하면 시작 때 보관·장착 선택을 마쳐야 합니다.

저장과 기록
일반 자동저장: bloodborne-hunt-v07. 검증 자동저장: bloodborne-hunt-qa-v1.
헤더의 일반/검증 이어하기로 각 진행을 따로 복원합니다. 마지막으로 선택한 진행만 별도 모드 키에 기억합니다.
검증 파일에는 setup.qa와 프리셋/지급목록을 기록합니다. 검증 배지와 저장파일명을 구분하며, 이 메타를 임의로 지우면 명령 재생 검증에서 거절됩니다.
검증모드의 승리는 정규 구성품으로 캠페인을 완주했다는 증거로 세지 않습니다. 정상 무기·화기·임무 원문 검증 기록은 별도로 유지합니다.

더 빠른 자동 점검
node scripts/qa-smoke.cjs는 검증 초기화·소모품·이동·저장 복원을 빠르게 점검합니다.
매 명령에 assertState는 계속 적용합니다. importSave 전체 재생은 시작 설정·임무 공개/완수·챕터 전환·중단/재개·최종 상태를 중심으로 점검합니다.
새 저장 형식이나 저장 복원 버그를 수정하는 작업에서는 해당 경로의 매 단계 재생 검증을 사용합니다.
기존 정상120명령의 실측에서 최종 재생만114ms, 매 단계 재생2629ms였습니다. 재생 명령 수는120회와7260회입니다. 저장검사 빈도는 정확성이 필요한 작업에 맞춥니다.
동일seed1의 같은첫적을 처치하는 공개명령은 정상25개, QA10개였습니다. 다른예에서는감소폭이작고실행시간이더길기도하므로전체테스트가일정배수로빨라진다고보장하지않습니다.

현재 구현 범위
기나긴 사냥 챕터1~3의 단일 사냥꾼 진행은 현재 확인한 범위에서 구현 완료입니다. 필수 미구현 항목과 추가 자료 요청은 없습니다.
남은 일은 실제 플레이에서 발견하는 조작·가독성·예외 개선입니다. 수동 플레이 점검은 자동 회귀와 별도입니다.
다른 캠페인과 멀티플레이는 사용자가 요청할 이후 범위입니다.
