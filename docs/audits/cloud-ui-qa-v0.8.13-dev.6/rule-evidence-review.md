# 예배당 속도 예외의 근거 검토

검토일: 2026-10-14 KST. 이 문서는 규칙 변경이나 공식 확정 판정이 아닙니다.

확보한 Git 소스의 `campaigns/long-hunt/data.json`에서 타일17의 전사문은 이 타일의 적 공격에 속도 -1을 적용합니다. 임무10과31의 전사문은 특수 공격을 교체하지만, 속도 감소 면제를 명시하지 않습니다. 이는 저장된 전사문을 읽은 결과이며 제외된 원본 사진을 다시 대조한 결과가 아닙니다. `source.filename`과 해시는 원문 위치 식별자일 뿐 사진을 확보했다는 증거가 아닙니다.

현행 `hunt-engine.js`는 `missionId === 'shelter'`에 타일 감산을 하지 않으며, `mission-engine.js`는 임무31 정의에 `ignoreTileSpeed`를 설정합니다. `hunt-combat-feedback.js`는 이 현행 정책과 공개된 최종 공격을 표시합니다. 엔진과 표시가 일치하는 검사는 공식 원문 근거 검사와 구분합니다.

[CMON 공식 FAQ v1.0](https://www.cmon.com/wp-content/uploads/2023/06/Bloodborne_Boardgame_FAQ_v1.0.pdf)의 전체 검색 가능한 본문을 확인했습니다. 1쪽의 지정 속도 전용 능력 처리, 3쪽의 기본/특수 위치에 있는 전용 능력도 공격이 아니라는 설명, 4쪽의 기나긴 사냥 임무20 정정은 확인할 수 있습니다. 예배당의 임무10/31 속도 면제를 확정하는 설명은 확보하지 못했습니다. 이 FAQ의 일반 전투 설명으로 두 면제를 정당화하지 않습니다.

[CMON 공식 규칙서 v1.1](https://www.cmon.com/wp-content/uploads/2023/06/Bloodborne_Rulebook_v1.1.pdf)의 검색 결과는 확보했지만 이번 열기에서 본문이 반환되지 않았습니다. 별도의 WIP 규칙서를 정식 v1.1 대조 결과로 대신하지 않았습니다.

결론: 일반 적의 예배당 속도 감소와 두 임무 예외의 **표시/엔진 일치**는 검증할 수 있습니다. 두 예외의 **공식 근거 감사는 미완료**이며 `officialConfirmed: false`입니다. 현행 엔진을 변경하거나 새로운 사용자 재정을 채택하지 않았습니다. 원본 임무10·31·타일17 또는 이를 직접 다루는 공식 판정과 대조하는 일이 남아 있습니다.
