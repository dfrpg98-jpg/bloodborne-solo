## 화면·영상 검토와 시간 계측

[시각 검토 범위](visual-review.md)는 실제 픽셀과 디코딩한 영상 PTS를 사용한다. 기본32의256PNG 및32WebM의256표본, 무료 변형15프레임을 확인했다. 추가 대표15경로의73PNG/166표본과 zoom/pan4를 확인했다. root도 빠른 표본의 시간차 프레임을 직접 확인했다. 지정 표본에서는 생존 인물의 지속 몸통 겹침이나 잘못된 정착 위치를 확정하지 못했다. 순간 무기 궤적과 몸 기울임, 정상 처치 제거, 지도 카메라 이동을 구분했다. DOM endpointGeometry는 논리 끝점이며 현재 canvas중간좌표의 증거가 아니다.

38490812586의 빠른6경로는 정상 연속 행동을 성공했지만 native 클릭 계측은250ms보다 긴 경우가 많았다. 38491810513에서는4경로의 실제142.6–225.6ms 후속을 확인했고2경로는252.9/276.6ms 타이밍 assertion으로 중단했다. 이는 게임 command/state 오류가 아닌 하네스 조건 실패다. 마지막38492083986에서 루드비히 무료 수락137.5/134.2ms, 도끼 연쇄236.6ms와 정상 다음 행동을 확인했다. 실제 간격을 바꾸어 보고하지 않는다. 빠른 표본은 실제 공개 버튼의 native pointer 클릭이며 엔진 직접 dispatch로 대신하지 않았다. 짝으로 누르는 구간의 중간 화면은 실제 phase 문구만 관찰하고, 완전한 저장 상태는 두 클릭 뒤 검증했다. 중간 상태를 모델 값으로 만들어 실제 snapshot이라고 기록하지 않았다.

전체 영상을 모든 프레임마다 검사한 것은 아니다. 더 짧은 이상을 전혀 배제한다는 보증이나 이전 공격/사망 애니메이션의 모든 프레임 유지 보증은 하지 않는다. 새 revision의 clearEffects는 소스 검토 후보로 남기며, 이번 표본에서 잘못된 생존 인물 배치/지속 몸통 겹침으로 확정된 새 BB로 등록하지 않았다. 실제 이미지·논리 상태·모델·시각 표본을 혼동하지 않는다.
