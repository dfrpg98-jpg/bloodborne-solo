# 하단 크기와 우측 바닥 정렬 · dev.39

사용자 주석의 2035×1252 화면에서 하단 높이는 260px, 우측 패널의 바닥은 44px 짧았습니다. 하단 행과 우측 높이 계산이 각각 260px와 216px를 쓰던 상태를 공통 `--loadout-row:209px`로 맞췄습니다. 실제 행 간격도 공통 변수로 연결해 작은 화면의 6px 간격과 기본 8px 간격을 함께 반영합니다.

기존 사용자 게임을 IAB에서 열고 읽기 전용 DOM 경계를 측정했습니다. 게임 행동을 실행하거나 개인 저장을 읽지 않았습니다. 화면 크기만 임시로 바꿨으며 검증 후 원래 크기로 복원했습니다. 측정값과 제품 해시는 [verification.json](verification.json)에 있습니다. 원본 화면 캡처는 Git에서 제외한 `test-results/compact-loadout-dev39/`에 남깁니다.

2035×1252, 1714×1252, 1231×1252, 1280×720의 4가지 데스크톱 화면과 좁은 800×1252 화면에서 아래 8항목, 총 40항목이 통과했습니다. 폭 721~800px는 기존 260px 반응형 높이를 유지해 버튼이 잘리지 않게 하며 우측 바닥은 같은 위치에 맞춥니다.

- 데스크톱 하단 전체 높이 209px, 좁은 800px 화면은 기존 260px
- 우측 패널과 하단 패널의 바닥 경계 차이 0px
- 공격 슬롯 3개의 같은 시작 높이·너비·높이
- 페이지 바깥 세로 넘침 없음
- 이동 단축키 설명이 이동 패널 안에 표시됨
- 화기가 공격 슬롯 위에 위치함
- 이동 버튼 하단과 단축키 설명이 겹치지 않음
- 공격 슬롯 하단이 무기 패널 안에 표시됨

2035×1252에서 지도 높이는 738px에서 789px로 늘었습니다. 슬롯 높이는 108.61px로 같으며, 1231×1252에서는 100.61px로 같습니다. 화기 상단 배치와 두 줄 Space 안내는 유지됩니다. 게임 판정·입력 처리·저장 형식은 수정하지 않았습니다.

재확인할 때는 8860 서버의 게임을 열어 위 크기로 각각 표시한 뒤 `.hunt-loadout`, `.hunt-decisions`, `#slots > .hunt-slot`, `.movement-shortcuts`, `#firearm`의 `getBoundingClientRect()`를 비교합니다. 2035×1252 기준 하단과 우측 패널의 바닥은 모두 1244px입니다.
