# 도움말을 따라 첫 검증 사냥 · 0.8.13-dev.12

2026-10-15. 실제 브라우저의 타이틀에서 시작했습니다. 경로 선택은 화면의 도움말과 현재 목표·가능한 버튼을 읽고 진행했으며, 엔진 호출·상태 주입·미리 만든 캠페인 체크포인트로 첫 이동/탐험을 건너뛰지 않았습니다. 기존 검증 진행은 UI로 내보내 로컬 백업했습니다. 개인 진행의 원시 저장은 Git에 게시하지 않습니다.

## 수정 전 실제 관찰

검증 모드·빠른 임무 검증·검증용 무기·중앙 등불로 시작했습니다. 준비 화면의 자동 시드는1061844653이며 처음에는 값을 바꾸지 않았습니다. 근력1장으로 이동을 시작해 왼쪽1칸에서 종료하고, 지구력1장으로 서쪽 출입구를 탐험했습니다. 골목길0°로 배치·진입한 뒤 이동을 마치고 차례를 종료하니 야수 사냥 무리와 조우했습니다.

[BB-036 / Issue51](https://github.com/dfrpg98-jpg/bloodborne-solo/issues/51). 맞서 공격 없이 공개된 기본 공격은 속도2·피해2였습니다. 회피에 충분한 기본 지구력과 빈 속도3 슬롯을 선택하고, 기존 도움말의 ‘대응을 정했다면 전투 처리’ 안내에서 생략된 회피 확정을 건너뛰어 재현했습니다. 실제 체력은6→4가 됐습니다. **카드·슬롯 선택은 회피 실행이 아니며 ‘회피’ 버튼을 눌러야 합니다.** 이 규칙은 올바른 동작이므로 자동 회피하도록 바꾸지 않습니다.

다른 안내 부족도 함께 확인했습니다. 검증 모드 준비 순서가 없었고, 파일 불러오기 경로는 타이틀/게임/준비 화면에서 이름이 달랐습니다. 타일 정보는 살펴본 타일을 유지하므로 사냥꾼의 현재 위치로 갱신하는 방법도 필요했습니다. 게임 안 용어 치환이 완성된 도움말의 ‘공격 카드’ 등을 다시 고치는 현상은 공유 도움말을 치환에서 제외해 보완합니다.

## 변경과 확인 범위

검증용 시작 순서를 첫 부분에 추가하고, 일반/검증 시작을 구분하며 첫 전투를7단계 안내에 포함했습니다. 회피는 카드→현재 빈 슬롯→회피 버튼→필요한 효과 선택→전투 처리로 명시합니다. 전용 능력/추가 타격의 회피 버튼도 단계 안내에서 구분합니다. 출입구 표시, 타일 정보의 현재 위치, 타이틀 ‘불러오기→저장 파일 선택’과 게임 ‘메뉴→불러오기’ 경로를 설명합니다.

수정 후에는 검증용 타이틀에서 **새 사냥을 처음부터 다시 시작**하고 동일 시드를 직접 입력해 첫 이동·탐험·배치·적 조우를 반복했습니다. 전투를 건너뛰어 준비한 것이 아니며, 새 전투 도달 시 내보낸 저장은 원래 전투와14,066바이트/SHA256까지 같았습니다. [수정 전 결과](evidence/baseline-result.json), [동일 조건 및 수정 후 결과](evidence/after-fix-result.json).
