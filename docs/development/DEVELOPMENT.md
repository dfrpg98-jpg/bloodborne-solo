# Bloodborne Solo 0.7.5

기준: 2026-10-12 KST

현재 목표는 1인용 기나긴 사냥 챕터 1~3이다. 다른 캠페인과 다인/온라인 플레이는 사용자가 이후에 검토하기로 정한 범위다. 현재 제공된 자료로 장치무기 15종, 화기 8종, 보상 정의 32종을 지원하며 성직자 야수·여성 야수 환자·이오세프카의 실제 카드 효과를 사용한다. 과거 출시 당시의 미구현 목록은 현재 안내에서 제거했다.

## 실행과 자료 경계

`hunt.html`이 정규 캠페인과 구성품 전투 연습 화면이다. `hunt-engine.js`는 명령 경계에서 상태를 복제하고 유효성을 검사하는 reducer이며 UI는 같은 명령과 조회 결과를 사용한다. `chapter-engine.js`가 지도 준비·회전·탐험·출현을, `mission-engine.js`가 조건부 공개·임무 상태·후속 분기·보스 예외를 처리한다. 무기·화기·보상·확장 적은 각 전용 모듈이 실제 전사와 실행 효과를 연결한다.

원본 `campaigns/long-hunt/data.json`/`data.js`, 구성품 원문, 출처와 해시, 수신 당시 `runtime`/`automated`/임시 정책은 자료 수집 기록으로 보존한다. 이 값만으로 현재 지원 여부를 판단하지 않는다. 실제 캠페인의 보스/NPC 정의와 호환용 임시 구성품 시험은 별도 경로다. 도입부 텍스트와 현재/과거 챕터에서 실제 공개된 카드 이미지만 게임의 이야기 열람에 제공한다. 모든 서사를 텍스트로 전사했다고 주장하지 않는다.

## 현재 규칙과 저장

새 사냥의 `rulesVersion`은 12이다. v0.7.5는 예배당의 동시 임무 판정에 새 규칙을 사용한다. 기존 규칙 11의 처리 순서와 명령 재생을 보존하고 저장 형식이나 브라우저 저장 키는 바꾸지 않는다. `bloodborne-hunt-save` version 1과 `bloodborne-hunt-v07`을 유지한다. 규칙 11/10/9/8/7/무버전 및 이전 v0.6/v0.5 저장은 당시 처리로 명령을 재생한다. 과거 임시 효과를 최신 실제 효과로 소급 변경하지 않는다.

챕터 준비에서는 중앙 등불의 왼쪽/중앙/오른쪽 시작 칸과 현재 장치무기 면을 명시적으로 고른다. 적 3종의 면/슬롯은 챕터마다 새로 추첨하고 지도 초기화에서는 유지한다. 챕터 2/3의 특별 준비 17은 중앙 등불·공동묘지·반대편 연결 타일·지하묘지와 나머지 탐험 타일을 구성한다. 챕터 전환은 12장 성장 덱·소지품·완료 카드 기록을 보존하며 현재 계몽 수와 과거 완료 이력을 구분한다.

## 임무와 전투 예외

번호 카드 1~60의 조건부 공개, 호위·포획·기부·안개·임무 부활, 최종 꿈과 캠페인 종료를 처리한다. 보스 시트 계몽과 챕터 임무 계몽은 별도 상태다. 성직자 야수의 1인 체력은 10/8이며 각 페이즈 행동 덱은 5장이다. 회복 행동은 계몽 제거·방어 2·행동 덱 섞기이고 체력 치유를 추가하지 않는다. 1페이즈 종료 당시 공개된 행동은 전환 후에도 남는다.

공식 FAQ의 기나긴 사냥 카드 20 수정은 공동묘지의 붉은 갈색 출현 칸이다. 챕터 2의 양 페이즈 초기화 재출현에 적용한다. 챕터 3은 인쇄된 현재 위치/페이즈 유지와 봉인 해제 조건을 따른다. 사망한 사냥꾼은 뒤의 치유로 되살아나지 않으며, 적과 떨어져 직접 피해가 빗나가도 살아 있는 사냥꾼의 공격 후 효과는 처리한다.

카드 56 공개와 카드 37의 호위 완료는 같은 예배당 이동 종료에 발생할 수 있다. 규칙서와 공식 FAQ에는 두 카드의 고유 우선순위가 없다. 새 규칙 12는 규칙서 24쪽의 가장 불리한 결과 원칙에 따라 판정한다. 28 보유·34/39 미보유로 33이 잠기는 경우는 예배당 임무를 먼저 적용한다. 나머지는 두 결과의 목표·비용·보상과 현재 자원을 보고 더 불리한 결과를 판정한다. 어느 순서든 호위 39의 유골·연발총 보상은 지급하며, 이미 해결한 56을 나중 39 획득으로 재판정하지 않는다. 이 UI는 일반 원칙에 근거한 해석이며 별도 제작사 정정이 아니다.

v0.7.4에서는 51/52의 자연 진입을 확인했고 정상 완료 경로는 미확보였다. v0.7.5에서는 원문 조건을 유지한 공개 명령만으로 두 임무의 정상 완료와 보상을 추가 확인했다. 51은 교단의 돌망치·기본 단총·시드90의 343명령으로 26을 완료하고 수혈액을 장착·사용하여 체력3/트랙8에 도달한다. 52는 야수의 발톱·기본 단총·시드90의 384명령으로 새 생존자2개를 수집·인도해 28과 사자의 선물을 장착하며 체력6/트랙8에 도달한다. 두 경로는 추가 시작 소모품이나 상태 편집을 사용하지 않는다. 각 기록은 해당 임무 완료 증거이며 그 기록 자체의 챕터3 최종 보스 승리를 주장하지 않는다. 모든 실제 제어기 결정과 매 행동 저장 가져오기 검사의 최종 실행 결과는 VERIFICATION.txt에 기록한다.

정상 56 동시 판정은315명령에서 대기 상태에 도달하고 두 결과 각각318명령까지 호위 보상 처리를 확인한다. 대기/선택 후 실제 저장 가져오기로 재생한다. mission-timing-v075.test.cjs의 이력 조립 경계와 chapel-natural-v075.test.cjs의 실제 자연 경로는 별도 근거다. 이동 뒤 도약 공격과 무기 후속 효과는 판정이 끝날 때까지 보류한다.

## 보상과 화면 가용성

보상은 32종 정의/30종 사용 효과/2종 사용불가 임무 물품을 구분한다. 정규 기나긴 사냥은 실제 카드가 주는 16종을 획득하며 독립 연습에서는 전체 정의를 선택할 수 있다. 공급 수량, 도구·문자 각각 2장, 화기 1개, 소진과 꿈 준비, 부착 슬롯/변형 후 재선택, 챕터당 사용 제한을 관리한다.

랜턴의 목적지 조회는 정상 등불 여부와 엔진의 `canTeleport`를 함께 사용한다. 안개 탈출 금지·같은 타일 제한·봉인 진입 금지로 목적지가 없으면 사용 버튼을 비활성화하고 이유를 표시한다. 실제 사용도 같은 목적지 목록을 검증한다. 필수 보상 획득 선택은 무기 전투 선택보다 먼저 해결하여 화면 선택이 덮어써지지 않게 한다.

## 지도

직접 제작한 SVG 20종과 클릭 영역은 `tile-geometry.js`를 공유한다. 사진에서 읽은 52칸·47출입구·등불 7·소모품 위치 12/토큰 14·적 출현 17의 논리 구조를 대조했다. 지도·타일 배치·자료실은 같은 도식을 사용하며 사진의 배경 픽셀을 넣지 않는다. 원근 제거 좌표는 전사 근사값이다. 배포에서는 지도 JPG를 제외하고 사용자의 원본과 다른 카드 사진은 보존한다.

## 검증 기록

보관 화기의 화면 정의는 실행과 같은 `firearmDefinition(s,id)`를 조회한다. 현행 저장에는 제공된 실제 카드를 표시하고, 이전 규칙 저장에는 당시 정의를 표시한다. 정의 조회는 저장 상태를 변경하지 않는다. 보유품의 순간이동 등불과 돌멩이 목적지 목록도 실제 이동 판정과 같은 정상 등불·안개·봉인 제한을 적용한다.

`RULES_CHECKLIST.json`과 TXT/XLSX는 동일 항목을 제공한다. 구현 상태, 자동/실제 브라우저 검증, 사용자의 직접 점검은 별개다. `RULES_AUDIT.txt`는 규칙 대조와 해석 경계를 기록한다.

전체 테스트 실행 수, 무기·화기 조합 검증, 임무 곁가지, 무기별 공개 명령 캠페인 결과, 기존 저장 복원과 실제 브라우저 검증은 이번 버전의 `VERIFICATION.txt`를 기준으로 한다. 테스트 파일의 존재나 조립 상태 검사를 새 게임부터의 자연 완주로 간주하지 않는다. 240개 무기/면/화기 조합은 규칙12와 보존 규칙10·11 각각 검사하여 총720개 전투 행렬을 이루며 본편 승리 결과와 구분한다. 새 규칙12의15무기 정상 본편 재생은 current-campaign-v075.test.cjs로 따로 대조한다. 과거 버전의 통과 수를 이번 버전 합계로 재사용하지 않는다.
