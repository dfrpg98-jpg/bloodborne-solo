복원한 장치무기 외형과 동작 · v0.8.5

현재 범위
v0.8.3의 에셋·외형·애니메이션을 복원하고, v0.8.4의 UI/UX·규칙·공개 정보·저장 호환을 유지합니다. 게임 전체를 v0.8.3으로 되돌리는 변경이 아닙니다.
제공된 복장·무기 자료와 원작의 구조·대표 동작을 참고해 제작했던 v0.8.3의 2D 외형을 사용합니다. 무기 15종·두 형태 30개와 720프레임을 복원합니다.
원작의 사진·게임 프레임을 잘라 쓴 캐릭터나 3D 리그·전체 콤보의 프레임 단위 복제가 아닙니다.

플레이에서 확인하기
기술을 지불한 변형이 성립하면 현재 형태와 무기를 든 외형이 바뀝니다. 무료 변형은 실제 수락·처리 후 반영합니다.
대상·기술·무기 슬롯을 고르고 실행합니다. 공격 선언만으로 결과를 예고하지 않으며 실제 전투 판정 뒤 해당 형태·슬롯의 베기·찌르기·쌍검·내려찍기·발톱·폭파·사격 연출을 보여줍니다.
85개 인쇄 공격 슬롯에 대표 2D 동작을 연결합니다. 원작 고유 콤보 85개를 추출한 수량이 아닙니다.
레이테르팔라슈의 수은탄 사격은 총검 공격으로 구별하며 별도 화기·소모품 효과와 혼동하지 않습니다.
토니트루스는 실제 충전 효과를 따라 전기를 표시합니다. 양쪽 규칙 구성에서 충전할 수 있으므로 내부 면 번호만으로 결정하지 않습니다.
일반 성검과 이질적인 성검은 같은 무기 조립 구조를 사용하며, 제공 자료의 형태 순서와 복장 차이를 유지합니다. 야수의 발톱은 제공 자료의 손 상태를 따릅니다.
속도·피해·슬롯·방해·회피·변형 비용과 현재 무기/화기의 규칙을 유지합니다.

미리보기와 현재 UI
weapon-gallery.html에서 복원한 무기와 두 형태를 고르고 해당 형태의 공격·변형·걷기·피격·쓰러짐을 확인합니다. 게임 진행과 저장을 바꾸지 않습니다.
본편의 무기 고유 효과와 화기 사용·준비 조건은 하단에서 항상 보이며, 의미 있는 현재 형태 이름과 최신 공개 정보 UI를 유지합니다.
