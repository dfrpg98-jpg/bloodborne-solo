지도에서 직접 행동하기 · v0.8.5

v0.8.3의 에셋·외형·애니메이션을 복원하고, v0.8.4의 UI/UX·규칙·공개 정보·저장 호환을 유지합니다. 게임 전체를 v0.8.3으로 되돌리는 변경이 아닙니다.
지도 직접 선택·행동 비용·불가 이유·준비 취소와 현재 UI 흐름은 유지합니다.
공개된 칸·출입구·적의 몸체/번호를 누르면 오른쪽에 해당 대상의 현재 행동을 보여줍니다. 선택만으로 기술을 쓰거나 타일·행동·임무·보상을 공개하지 않습니다.
이동 시작과 첫 이동/탐험은 기존 MOVE와 STEP/EXPLORE 순서를 따릅니다. 공격에서는 대상·기술·슬롯을 고르고 실행한 뒤 실제 대응 선택을 처리합니다.
화기·회피·보상·강제 이동 등 전략 선택은 필요한 시점에 남깁니다. 숨겨진 정보가 공개된 뒤의 실행을 준비 선택 취소처럼 되돌리지 않습니다.
복원한 캐릭터와 번호 토큰은 같은 실제 위치와 대상에 연결하며, 동작 연출이 비용·피해·규칙 이동을 결정하지 않습니다.
현재 주 목표·계몽 단서 조건·공개된 전체 임무와 무기/화기 효과 상시 표시, 적 도감과 현재 공용 덱 기록을 유지합니다.
60~180% 줌·팬·현재 위치·맞춤은 규칙 행동이 아닙니다. 자세한 조작은 HUD_GUIDE.txt와 ANIMATION_CAMERA_GUIDE.txt에 있습니다.
이번 복원·현재 UI·기존 저장·패키지·설치의 실제 검사 범위는 VERIFICATION_v085.txt에서 확인하세요. 과거 버전 검증 기록은 당시 범위의 기록입니다.
