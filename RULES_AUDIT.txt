1. 판단 기준과 자료

사용자 제공 한국어 규칙서28쪽 전체와 캠페인 카드1~60, 적3종6면, 타일20종, 스탯/소모품/보상 목록을 대조했다. 이번 후속 구현은10쪽 챕터 준비,17쪽 보상/활성화,23~25쪽 보스·NPC·꿈·초기화·캠페인 진행과 후속 임무를 다시 대조했다. 원문은 길게 인용하지 않고 확인 가능한 조건으로 정리했다.
실행 코드와 실제 테스트 파일을 읽어 확인했으며 감사 담당은 엔진/UI를 수정하지 않았다. 최종 실제 실행 결과/개수는 VERIFICATION.txt에 기록한다. 기존171/196개 기록을 이번 버전 합계로 재사용하지 않는다.
이후 전달된 성직자 야수 전사, 참고자료4장과 화염방사기 문장을 새 규칙9에 적용했다. 기존 규칙8 이하의 임시 효과는 저장 재생 경로에 보존한다. 실물 효과 검증과 과거 임시 캠페인 회귀를 구분한다. 전체 보드게임 완료 또는 전체 규칙100%로 표시하지 않는다. v0.7.2는 사진42장/TXT1개를 추가 판독하여 규칙10에 연결했으며 자세한 현재 범위는 SOURCE_REVIEW.txt를 확인한다.

2. v0.7.1 이야기 표시와 자료 불필요 예외

R10/7·12쪽: 도입부 텍스트는 기존 preface.intro.narrative를 사용한다. 번호 카드1~60의 이야기 원문은 이미 제공된 카드 이미지다. 새 사냥 준비 및 게임의 공개 이야기 열람 UI를 연결하며 현재 mission.revealed와 history[].revealed에 있는 카드만 표시한다. 미공개 카드의 제목/이동 링크를 만들지 않는다. 열람과 확대는 표시 전용이며 게임 상태·명령을 수정하지 않는다. 이미지 원문을 텍스트 전사 완료라고 주장하지 않는다.
R20/15쪽: 새 타일을 어떻게 놓아도 전체 출입구가 닫히면 반환하고 적합한 타일을 다시 뽑는다. 규칙서에는 마지막 한 장을 예외로 허용한다는 문장이 없다. 새 rulesVersion8 이상에서 마지막 카드에도 열린 출입구를 요구하며 적합한 대체가 없으면 입력 상태를 보존해 거절한다. 챕터2~3 카드17의 특수 선배치는 별도 지정 준비다. 기존7/무버전 사냥·지도 저장은 원래 처리로 재생한다.
R46/21쪽: 독·발광 공격 키워드의 일반 부여 처리를 연결한다. 회피/취소된 공격은 부여하지 않으며 스탯 면역과 마비 안개로 제거된 키워드를 존중한다. 이미 가진 상태는 중복 증가하지 않는다. 발광을 처음 부여한 타격에는 추가 피해를 더하지 않고 이후 공격에 적용한다. 실제 일반 적3종6면에는 독/발광 공격이 없다. 새 이오세프카·여성 야수 환자는 실제 독 공격을 사용하며 규칙10의 추가 교단 종복/거인은 인쇄된 발광 공격·능력을 연결한다.
R64/16·24쪽: 적 경로·같은 슬롯 활성화·피규어 재배치 및 새 복수 적 상호작용 반격 순서는 플레이어가 고른다. 각 선택에 가장 불리한 결과 원칙을 안내한다. 규칙은 자동 최악 평가를 요구하지 않으며 실제 불리함 판단은 수동이다. 구저장의 반격 순서는 재생 호환을 위해 그대로 둔다.
R47/21쪽: 기존 일반 적6면에는 없던 흰 배경 기본/특수 능력을 추가 실물 적에서 확인했다. 교단 거인의 특수 능력과 하인의 받아넘기기 등은 흰 능력으로 구분하고 인쇄된 방해 예외를 적용한다. 마비 안개는 공격 효과를 제거하지만 흰 능력을 제거하지 않는다.

기존 요청과 유지한 수정

A01 시작 칸: 규칙10쪽은 매 챕터 중앙 등불의 원하는 칸을 고른다. 첫 시작 및 다음 챕터 준비 UI에서 왼쪽/중앙/오른쪽을 명시적으로 고른다. chapter-engine.create(startSpace), hunt-engine.startNextChapter(), start-placement와 실제 DOM/전환 테스트가 근거다.
A02 중앙 등불: 일반 등불과 안개 내부 아무 칸을 상호작용 목적지로 허용한다. 보상 랜턴은 정상 등불만 허용한다. 봉인된 챕터3 지하묘지는 canEnter()가 이동과 순간이동을 모두 차단한다.
A03 결합 상호작용: 폐가의 소모품과 구조를 카드1장으로 함께 선택하며 적의 선행 반격이 끝나야 효과를 해결한다.
A04 예배당 교환: 성배 교단 예배당의 명명 칸에서 보유 소모품 또는 상자 획득 후 선택한 카드를 교환한다. 교환은 유지1개(상한3), 추가 스탯 비용 없음, 소모품 일반 효과 없음이다. 사망으로 효과가 중단되면 보유품과 미개봉 소모품을 소비하지 않는다.
A05 골수 가루: 자기 차례의 소진된 장착 비지속 도구/문자1장을 준비한다. 준비된/보관된/파편/화기/잘못된 대상/잘못된 시점은 소비 없이 거절한다. 기존 자연 획득 v0.6.1 인스턴스도 사용한다.

5. 챕터 사이 진행과 보상

25쪽: 챕터를 완수하면 마지막 꿈에서 유지를 사용하고 성장/소지품/완료 계몽을 보관한다. ENTER_BETWEEN_CHAPTERS는 실제 도달 가능한 장비 준비 상태다. 도구/문자 각각2장, 화기1개 제한 내에서 보관품을 교체한다. START_NEXT_CHAPTER는 미선택 시작 칸/잘못된 면/남은 획득 선택을 거절한다.
새 챕터는 성장한12장과 소유품을 빼고 공급을 재구성하며, 트랙/라운드/체력/슬롯/상태/시장/덱/적 면/슬롯을 준비한다. 현재 완료 목록은 비우고 지난 기록을 분기에 보존한다. 장착 보상은 준비 상태다. 챕터3 뒤에는 다음 챕터 버튼이 없다.
17쪽/보상:32종을 등록한다. 기존 실행16종에 추가 효과14종을 연결하며 작은 오르골·의식용 재료2종은 사용불가 임무 물품으로 보관한다. 실행 효과30종과 정의32종을 구분하고 화기를 보상 종류 수에 합산하지 않는다. 규칙11의 전투 연습에서는 시작 보상을 선택해 인쇄 공급 및 도구·문자 각각2장 제한으로 효과를 확인할 수 있다. 정규 캠페인에 없는 획득 조건은 만들지 않는다.
대상/목적지 사전 검증과 무효 선택 롤백, 합성 공격 보너스, 동속 방해, 무료 변형, 자동 회피와 소진/꿈 회복을 확인한다. 일부 기존 source runtime=reference는 수집 당시 기록이며 실제 supported 목록과 혼동하지 않는다.

6. 남은 구현과 확인 한계

남은 보상16종의 효과·보관은 이번 규칙11에 연결했다. 다른 캠페인에서 이 보상들을 획득하는 임무 조건은 해당 캠페인의 자료가 필요하다. 작은 오르골/의식용 재료는 원문 사용불가이므로 임의 사용 효과를 만들지 않는다.
다른 세 캠페인(커져가는 광기/교단의 비밀/야남 구시가지의 몰락)과 관련 보스/임무 연결,2~4인 실행과 온라인 협동은 남아 있다. 현재 새 규칙10은 장치무기15종, 추가화기7종+기본 단총, 신규 실물 적12종의 독립 연습을 지원한다. 독/발광과 추가 흰 배경 능력은 제공된 실제 카드에 연결했다. 참고자료 세 폴더에 다른 캠페인의 전체 카드·보스 양면/행동 자료가 모두 있는 것은 아니다.
마지막 봉쇄 타일 예외는 새 사냥에서 제거했고 구저장 재생에만 유지한다. 가장 불리한 결과는 선택 UI 안내에 따라 사용자가 판단한다. 모든 물리 토큰 전체 공급 제한까지 일반화하지 않았다.
초대장 제외와1인용 사냥꾼의 종 제한은 의도된 범위다. 사용자 제공 보상32종/68장과 기본판 인쇄 보상25장을 같은 수량으로 주장하지 않는다.
