1. 판단 기준과 자료

사용자 제공 한국어 규칙서28쪽 전체와 캠페인 카드1~60, 적3종6면, 타일20종, 스탯/소모품/보상 목록을 대조했다. 이번 후속 구현은10쪽 챕터 준비,17쪽 보상/활성화,23~25쪽 보스·NPC·꿈·초기화·캠페인 진행과 후속 임무를 다시 대조했다. 원문은 길게 인용하지 않고 확인 가능한 조건으로 정리했다.
실행 코드와 실제 테스트 파일을 읽어 확인했으며 감사 담당은 엔진/UI를 수정하지 않았다. 최종 실제 실행 결과/개수는 VERIFICATION.txt에 기록한다. 기존171/196개 기록을 이번 버전 합계로 재사용하지 않는다.
이후 전달된 성직자 야수 전사, 참고자료4장과 화염방사기 문장을 새 규칙9에 적용했다. 기존 규칙8 이하의 임시 효과는 저장 재생 경로에 보존한다. 실물 효과 검증과 과거 임시 캠페인 회귀를 구분한다. 전체 보드게임 완료 또는 전체 규칙100%로 표시하지 않는다.

2. v0.7.1 이야기 표시와 자료 불필요 예외

R10/7·12쪽: 도입부 텍스트는 기존 preface.intro.narrative를 사용한다. 번호 카드1~60의 이야기 원문은 이미 제공된 카드 이미지다. 새 사냥 준비 및 게임의 공개 이야기 열람 UI를 연결하며 현재 mission.revealed와 history[].revealed에 있는 카드만 표시한다. 미공개 카드의 제목/이동 링크를 만들지 않는다. 열람과 확대는 표시 전용이며 게임 상태·명령을 수정하지 않는다. 이미지 원문을 텍스트 전사 완료라고 주장하지 않는다.
R20/15쪽: 새 타일을 어떻게 놓아도 전체 출입구가 닫히면 반환하고 적합한 타일을 다시 뽑는다. 규칙서에는 마지막 한 장을 예외로 허용한다는 문장이 없다. 새 rulesVersion8 이상에서 마지막 카드에도 열린 출입구를 요구하며 적합한 대체가 없으면 입력 상태를 보존해 거절한다. 챕터2~3 카드17의 특수 선배치는 별도 지정 준비다. 기존7/무버전 사냥·지도 저장은 원래 처리로 재생한다.
R46/21쪽: 독·발광 공격 키워드의 일반 부여 처리를 연결한다. 회피/취소된 공격은 부여하지 않으며 스탯 면역과 마비 안개로 제거된 키워드를 존중한다. 이미 가진 상태는 중복 증가하지 않는다. 발광을 처음 부여한 타격에는 추가 피해를 더하지 않고 이후 공격에 적용한다. 실제 일반 적3종6면에는 독/발광 공격이 없다. 새 이오세프카·여성 야수 환자는 실제 독 공격을 사용하며 발광은 시험용 키워드 회귀로 범위를 구분한다.
R64/16·24쪽: 적 경로·같은 슬롯 활성화·피규어 재배치 및 새 복수 적 상호작용 반격 순서는 플레이어가 고른다. 각 선택에 가장 불리한 결과 원칙을 안내한다. 규칙은 자동 최악 평가를 요구하지 않으며 실제 불리함 판단은 수동이다. 구저장의 반격 순서는 재생 호환을 위해 그대로 둔다.
R47/21쪽: 흰 배경 기본/특수 능력의 일반 규칙은 알려져 있지만 현재6면에는 해당 인쇄 능력이 없다. 임시 보스 회복은 이미 ability로 처리한다. 제공되지 않은 실제 능력의 효과를 창작하거나 전체 지원으로 표시하지 않는다.

A05 골수 가루: 자기 차례의 소진된 장착 비지속 도구/문자1장을 준비한다. 준비된/보관된/파편/화기/잘못된 대상/잘못된 시점은 소비 없이 거절한다. 기존 자연 획득 v0.6.1 인스턴스도 사용한다.

5. 챕터 사이 진행과 보상

25쪽: 챕터를 완수하면 마지막 꿈에서 유지를 사용하고 성장/소지품/완료 계몽을 보관한다. ENTER_BETWEEN_CHAPTERS는 실제 도달 가능한 장비 준비 상태다. 도구/문자 각각2장, 화기1개 제한 내에서 보관품을 교체한다. START_NEXT_CHAPTER는 미선택 시작 칸/잘못된 면/남은 획득 선택을 거절한다.
새 챕터는 성장한12장과 소유품을 빼고 공급을 재구성하며, 트랙/라운드/체력/슬롯/상태/시장/덱/적 면/슬롯을 준비한다. 현재 완료 목록은 비우고 지난 기록을 분기에 보존한다. 장착 보상은 준비 상태다. 챕터3 뒤에는 다음 챕터 버튼이 없다.
17쪽/보상:32종 중16종을 실행한다. 기존6종은 혈석의 파편,랜턴,달,손톱자국,피의 기쁨,눈이다. 추가10종은 정령의 빈 껍데기,이브리에타스의 전조,사형 집행인의 장갑,고대 사냥꾼의 유골,야수의 포효,사자의 선물,이오세프카의 수혈액,사냥,오에돈의 꿈틀거림,형태 없는 오에돈이다. 화기는 이16종 보상 종류 수에 합산하지 않는다.
대상/목적지 사전 검증과 무효 선택 롤백, 합성 공격 보너스, 동속 방해, 무료 변형, 자동 회피와 소진/꿈 회복을 확인한다. 일부 기존 source runtime=reference는 수집 당시 기록이며 실제 supported 목록과 혼동하지 않는다.

6. 남은 구현과 확인 한계

보상16종 미연결: 아리안나의 피,작은 오르골,아데라의 피,공허로의 외침,야수 사냥의 횃불,작은 토니트루스,혈석의 덩어리,눈물의 혈정석,여왕의 살점,결혼 반지,의식용 재료,성찬식,광휘,타락,인도,야수. 작은 오르골/의식용 재료는 원문 사용불가이므로 임의 사용 효과를 만들지 않는다.
다른 세 캠페인(커져가는 광기/교단의 비밀/야남 구시가지의 몰락), 기본판 네 사냥꾼/장치 무기,2~4인 차례/대상/전달/수량/보스 체력/NPC면과 온라인 협동은 미구현이다. 추가3화기는 새 규칙9에서 각 실제 고유 효과와 준비 비용을 실행한다. 독은 실제 NPC/여성 공격을 연결했고 발광은 현재 원문 공격이 없어 시험용 키워드로 회귀한다. 일반 기본/특수 슬롯의 흰 배경 전용 능력은 구체 자료 연결이 남아 있다.
마지막 봉쇄 타일 예외는 새 사냥에서 제거했고 구저장 재생에만 유지한다. 가장 불리한 결과는 선택 UI 안내에 따라 사용자가 판단한다. 모든 물리 토큰 전체 공급 제한까지 일반화하지 않았다.
초대장 제외와1인용 사냥꾼의 종 제한은 의도된 범위다. 사용자 제공 보상32종/68장과 기본판 인쇄 보상25장을 같은 수량으로 주장하지 않는다.

8. 검증과 사용자 점검

RULES_CHECKLIST.json/TXT/XLSX는 84행의 동일 자료다. 구현 상태, 근거 수준, 사용자의 직접 점검은 별개이며 직접 점검은 모두 미점검이다. 실제 함수/파일/테스트명을 대조했다. 자동 테스트가 존재하거나 통과해도 사용자의 확인 완료로 표시하지 않는다.
campaign-progression은64시드×2챕터의128개 준비 상태와 실제122명령 챕터1 완료 뒤 전환/수량/성장/시작칸/정확 저장을 확인한다. 이전 규칙 방식으로 완료한 저장의 새 전환/전체 명령 재생도 별도로 확인한다. later-missions는 후속 분기와 경계에 조립 상태도 사용한다. later-rewards는 실제 효과와 통합 전투, campaign-ui는9개 DOM 조작을 확인한다. 실제 새 사냥에서 캠페인을 잇는 전체 명령 근거와 최종 개수는 VERIFICATION.txt를 참고한다.
별도 브라우저 검증은 실제 완료 저장 불러오기→장비 준비→미선택 차단→오른쪽 시작칸/면1/보관 장총 장착→챕터2 시작을 확인했다. 개발자 자동 회귀와 사용자가 직접 해 볼 점검은 구분한다.
부분/미구현/범위 제외·임시 구성품이 남아 있으므로 전체 규칙 완성률을 계산하지 않는다. 이번 실제 보스/NPC 효과의 분기·경계 검증과 자연 명령 캠페인 결과는 최종 VERIFICATION.txt에 별도로 기록한다.
