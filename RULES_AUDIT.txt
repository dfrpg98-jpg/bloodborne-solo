1. 자료와 판단 기준

사용자 제공 한국어 규칙서 28쪽 전체, 기나긴 사냥 번호 카드 1~60과 준비/도입 자료, 일반 적 3종 6면, 지도 20종, 참고자료의 장치무기·적·화기·스탯·소모품·보상을 실행 코드와 대조했다.
성직자 야수의 양 페이즈 수치와 행동은 사용자 직접 전사, 여성 야수 환자·이오세프카와 추가 무기/화기는 참고자료를 적용한다. 현재 기나긴 사냥을 위해 추가로 요청하는 자료는 없다.
CMON 공식 FAQ v1.0의 공통 예외와 기나긴 사냥 카드 20 수정도 확인했다.
https://www.cmon.com/wp-content/uploads/2023/06/Bloodborne_Boardgame_FAQ_v1.0.pdf
원본 수집 자료의 runtime/automated/임시 정책은 수신 당시 기록이다. 현재 실행 범위는 엔진과 최신 점검표를 기준으로 하며 원본과 출처를 변경하지 않는다.

2. 준비·이동·상호작용

8~10쪽: 체력 6, 기본 스탯 12장, 업그레이드 공급/시장, 1인 소모품 더미, 적 면/슬롯과 챕터 타일 준비를 대조했다. 매 챕터 중앙 등불의 왼쪽·중앙·오른쪽 시작 칸과 선택한 장치무기 면을 고른다. 현재 장치무기 15종의 양면과 화기 8종을 지원한다.
14~15쪽: 스탯 행동 비용, 최대 2칸 이동, 실제 경로 추격, 출입구 연결·회전·발견 타일 의무 진입, 공개 즉시 적/소모품 배치, 적 종류별 피규어 4개와 가장 먼 재배치를 처리한다. 임무 적은 일반 재배치 후보에서 보호한다.
새 사냥은 마지막 탐험 타일도 전체 출입구 봉쇄를 금지한다. 적합한 대체가 없으면 입력 상태를 보존해 거절한다. 카드 17 특별 선배치는 지정 준비 규칙을 따른다.
16~17쪽: 상호작용의 선행 반격을 먼저 처리하고 소모품 획득·호위·교환의 결합 선택을 해결한다. 사망으로 중단되면 미실행 교환 품목을 소비하지 않는다.
성배 교단 예배당은 지정 칸에서 소모품 1장으로 유지 1개(상한 3)를 얻는다. 상자 획득 뒤 선택한 카드를 교환할 수 있으며 추가 스탯 비용이나 소모품의 일반 효과를 붙이지 않는다.
골수 가루는 자기 차례에 소진된 장착 비지속 도구/문자 1장을 준비한다. 준비된/보관된 보상, 지속 혈석, 화기와 잘못된 시점은 소비 없이 거절한다.

3. 전투·상태·처치

18~22쪽: 빈 슬롯·손패 보충, 적 행동 선공개, 공용 기본 3/특수 2/능력 1 덱, 소진 후 재구성, 지정 속도와 동속 처리, 회피·방해·기절·추가 타격, 즉시 스탯 효과와 전투 후 반응을 대조했다.
흰 배경 능력은 공격과 구분하고 인쇄된 예외를 적용한다. 방어는 즉시 적용하며 마비 안개는 공격 키워드를 제거해도 흰 능력을 제거하지 않는다. 화기의 사용 조건은 공개된 행동 종류와 각 카드의 실제 효과를 따른다.
독·발광은 회피/취소되지 않은 실제 공격으로 부여하며 면역/키워드 제거를 존중한다. 상태는 중복 증가하지 않고 처음 발광을 부여한 타격에 추가 피해를 소급하지 않는다.
동시 피해, 실제 처치에 따른 유지와 반응, 사망으로 인한 후속 효과 중단을 처리한다. 임무의 ‘처치 대신 부활’은 실제 처치로 세지 않는다.
FAQ: 서로 떨어져 직접 피해를 받지 않아도 공격 후 치유 등은 살아 있는 사냥꾼에게 적용한다. 이미 사망한 사냥꾼에게 뒤의 치유를 적용하지 않는다.
여러 적의 경로·같은 슬롯 활성화·재배치·반격 순서는 플레이어 선택이며 규칙의 가장 불리한 결과 안내를 표시한다. 전술별 유불리를 엔진이 자동 평가하는 규칙으로 바꾸지 않는다.

4. 캠페인·임무와 해석 경계

12~13쪽/카드 1~60: 조건부 공개·계몽·승패, 생존자 호위/도주/포획/인도, 시체 봉헌, 진료소와 예배당 분기, 야수 토벌·동행 NPC·기부, 안개/봉인과 임무 적 부활을 실행한다. reveal 참조 목록을 무조건 한꺼번에 공개하지 않는다.
현재 계몽은 이번 챕터의 완료 결과만 집계하고 과거 완료 기록은 후속 분기에 보존한다. 보스 시트 계몽과 챕터 임무 토큰은 별개다.
카드 17의 챕터 2~3 준비는 중앙 등불·공동묘지·반대편 무작위 연결 타일·지하묘지를 배치한다. 1인용은 선배치 4/탐험 덱 5, 총 9타일이다. 연결 타일은 미사용 타일 중 출입구 2개 이상이며 일반 준비의 무작위 타일과 혼동하지 않는다.
카드 39/56 원문 재대조: 카드 56 공개와 카드 37의 호위 완료는 같은 예배당 이동 종료에 발생할 수 있다. 규칙서와 공식 FAQ에는 두 카드의 고유 우선순위가 없다. 새 규칙 12는 규칙서 24쪽의 가장 불리한 결과 원칙에 따라 판정한다. 28 보유·34/39 미보유로 33이 잠기는 경우는 예배당 임무를 먼저 적용한다. 나머지는 두 결과의 목표·비용·보상과 현재 자원을 보고 더 불리한 결과를 판정한다. 어느 순서든 호위 39의 유골·연발총 보상은 지급하며, 이미 해결한 56을 나중 39 획득으로 재판정하지 않는다. 이 UI는 일반 원칙에 근거한 해석이며 별도 제작사 정정이 아니다.
12~13쪽 카드 공개·보상,24쪽 일반 원칙과37/39/56 사진을 다시 확인했다. 과거 규칙11의 고정 처리 순서는 기존 저장에서 유지한다. 새 규칙12의 자연315명령 판정 대기와 두318명령 결과를 저장/실제 제어기로 대조한다.33의 현재 생존자는 해당 결과를 고르면 같은 도착에 바로 전달하며59는 보유 소모품 수를 안내한다.
v0.7.4에서는 51/52의 자연 진입을 확인했고 정상 완료 경로는 미확보였다. v0.7.5에서는 원문 조건을 유지한 공개 명령만으로 두 임무의 정상 완료와 보상을 추가 확인했다. 51은 교단의 돌망치·기본 단총·시드90의 343명령으로 26을 완료하고 수혈액을 장착·사용하여 체력3/트랙8에 도달한다. 52는 야수의 발톱·기본 단총·시드90의 384명령으로 새 생존자2개를 수집·인도해 28과 사자의 선물을 장착하며 체력6/트랙8에 도달한다. 두 경로는 추가 시작 소모품이나 상태 편집을 사용하지 않는다. 각 기록은 해당 임무 완료 증거이며 그 기록 자체의 챕터3 최종 보스 승리를 주장하지 않는다. 모든 실제 제어기 결정과 매 행동 저장 가져오기 검사의 최종 실행 결과는 VERIFICATION.txt에 기록한다.
도입부와 현재/과거 챕터에서 실제 공개된 임무 이야기만 게임에서 열람한다. 미공개 카드의 제목·링크를 미리 표시하지 않는다. 이미지의 이야기 원문을 전부 텍스트 전사했다고 주장하지 않는다.

5. 보스·NPC·안개·초기화

23쪽: 실제 성직자 야수 1인 체력은 1페이즈 10/2페이즈 8이며 페이즈별 행동 덱은 5장이다. 페이즈 전환은 치유·초과 피해 폐기·이미 공개된 행동 지속을 처리한다. 회복 행동은 계몽 제거·방어 2·행동 덱 섞기이고 체력 치유를 추가하지 않는다.
실제 카드의 화기 소진 계몽, 범위 공격·추가 공개·강제 이동·회피 보너스와 방해/회피 불가를 연결한다. 여성 야수 환자는 챕터별 선택한 양면을 유지하며 이오세프카는 실제 1~2인 면(체력 10)의 효과를 1인 실행에 적용한다.
24쪽: 일반 초기화는 보스의 현재 위치/페이즈를 유지하고 치유한다. 일반 적·소모품과 임무 적은 인쇄된 우선순위/부활 규칙으로 복원한다. 적 면과 슬롯을 다시 뽑지 않는다.
챕터 2 카드 20/22는 FAQ 수정에 따라 양 페이즈 모두 공동묘지 붉은 갈색 출현 칸에 재출현한다. 2페이즈 피해 면역·안개 제거·지하묘지 진입 승리·추가 활성화를 처리한다.
챕터 3 카드 41~43은 현재 계몽 2개 또는 두 번째 초기화에서 봉인을 해제한다. 보스는 현재 위치/페이즈를 유지하며 치유하고 시트 계몽을 제거한다. 라운드말 접근/공격과 회복 행동의 야수 출현, 카드 55의 출현 중단을 적용한다.
안개가 생긴 타일은 일반 적/등불 제거와 일반 출현 억제를 처리한다. 꿈 이외의 방법으로 안개 타일을 벗어날 수 없다. 중앙 등불 상호작용은 정상 등불과 안개 안의 칸을 목적지로 허용하고 봉인 진입을 검사한다.
랜턴은 정상 등불 중 실제 이동 가능한 목적지만 보여 준다. 현재 안개·같은 타일·봉인 조건으로 목적지가 없으면 사용 불가와 이유를 표시한다. 조회 목록과 실제 사용의 목적지 검증을 일치시켰다.

6. 꿈·성장·챕터 전환

23~25쪽: 꿈에서 모든 스탯을 합쳐 유지 소비·시장 보충·업그레이드 채택/버림을 처리하고 덱 12장을 유지한다. 체력·상태·화기·보상·덱을 준비한 뒤 정상 등불로 귀환한다. 일반 꿈/라운드와 챕터 완수의 마지막 꿈을 구분하며 완수 꿈에서는 트랙을 전진시키지 않는다.
챕터 완수 뒤 장비 준비에서 도구/문자 각각 2장과 화기 1개 제한으로 보관품을 교체한다. 필수 획득 선택을 먼저 해결하며 다음 챕터 시작 칸/무기면을 고르지 않으면 시작할 수 없다.
성장 덱·소모품·보상·화기·완료 이력을 보존하고 새 챕터의 공급/시장/트랙/라운드/체력/슬롯/덱/지도/적 배정을 준비한다. 챕터 3 완수 뒤 다음 챕터를 만들지 않는다.

7. 보상과 범위

보상 32종을 등록한다. 30종의 사용 효과를 연결하고 작은 오르골·의식용 재료 2종은 인쇄된 사용불가 임무 물품으로 보관한다. 화기는 이 보상 종류 수와 별도로 센다.
기나긴 사냥 카드가 주는 16종 보상의 획득을 연결한다. 다른 캠페인의 획득 조건을 현재 캠페인에 추가하지 않는다. 별도 전투 연습에서는 32종을 공급 수량과 장착 제한 내에서 선택할 수 있다.
대상/목적지 사전 검증·무효 선택 롤백, 합성 공격 보너스, 슬롯 부착과 변형 후 재선택, 준비/소진·꿈 회복, 챕터당 1회·처치/진입 반응을 처리한다. 지속 혈석을 소진 보상으로 취급하지 않는다.
예를 들어 광휘/타락의 챕터별 횟수는 꿈·골수 가루로 되돌리지 않는다. 여왕의 살점은 차례 시작 창을 사용하고 인도는 정상 이동/추격/탐험으로 이어진다. 횃불은 비보스 진입 반응이며 독립 화기 공격의 공격 시점 보상과 슬롯 없는 공격의 제한을 구분한다.
초대장 제외는 사용자 지시이고 사냥꾼의 종은 1인용 제한이다. 사용자 자료의 보상 32종/68장을 기본판 인쇄 수량과 같은 것으로 주장하지 않는다.
다른 캠페인과 2~4인/온라인 협동은 사용자가 정한 이후 범위다. 다인 체력·타깃·장비 전달을 1인 실행 완료의 남은 필수 작업으로 표시하지 않는다. 물리 토큰 전체 공급과 모든 캠페인/확장의 규칙까지 일반화했다는 주장은 하지 않는다.

8. 지도 도식과 저장

사진과 SVG 20종의 논리 구조를 대조했다. 52칸·47출입구·등불 7·소모품 위치 12/초기 토큰 14·출현 17(금 6/적갈 5/보라 6)을 유지한다. 마당 등불은 W/E/S 출입구이며 사진에 없는 N을 추가하지 않는다.
tile-geometry.js를 지도/배치/자료실 렌더와 클릭 영역이 공유한다. 사진 배경 픽셀을 사용하지 않으며 촬영 원근을 제거한 경계는 근사 전사다. 픽셀·물리 치수 동일성이나 권리 허가 판정을 인증하지 않는다.
배포 ZIP에서 지도 JPG 20장을 제외하고 사용자의 원본과 다른 카드 사진을 보존한다.

9. 검증 기록 읽기

RULES_CHECKLIST.json/TXT/XLSX는 같은110항목의 구현 상태와 근거를 담는다. 사용자의 직접 점검은 개인 확인 기록으로 자동/실제 브라우저 검증과 별개다. 혼합된 범위의 행을 전체 보드게임 완성률로 계산하지 않는다.
자동 검사는 단위/통합/조립 상태 회귀와 공개 명령으로 새 게임부터 진행한 결과를 구분한다. 무기 15종×시작 면 2×화기 8종의 240조합은 현행 규칙12와 보존 규칙10·11에서 각각 점검한다(총720개 전투 행렬). 모든 조합의 캠페인 승리를 뜻하지 않으며 규칙12의15무기 본편 재생은 별도 검사다.
과거 실제 저장39개와 독립 배포 엔진의 정상 상태1366개, 총1405개를 정확 복원했다.
이번 버전의 최종 실행 수, 임무 곁가지와 무기별 본편 결과, 명령 수/저장 체크포인트, 이전 저장 원상 복원 및 실제 브라우저 검증은 VERIFICATION.txt에 기록한다. 과거 버전의 통과 수나 작업 중 탐색 결과를 최종 결과로 재사용하지 않는다.
