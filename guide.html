기나긴 사냥 챕터 1~3 플레이하기

실제 지도에서 사냥 →

후속 임무와 챕터 전환 연결판준비·임무·보상·성장 보관을 연결해 기나긴 사냥을 마지막 챕터까지 진행합니다. 성직자 야수·여성 야수 환자·이오세프카의 전투는 사용자 승인 임시 구성품을 사용합니다.

실행과 시작 칸

ZIP 전체를 압축 해제하고 hunt.html을 Chrome/Edge로 여세요. 인터넷이나 개발 도구 설치는 필요하지 않습니다. 첫 실행에서 ‘기나긴 사냥 · 챕터 1’을 고르고 중앙 등불 도식의 왼쪽·중앙·오른쪽 칸 중 원하는 곳을 선택합니다. 정상 자동 저장이 있으면 이어서 진행하며 ‘새 사냥’에서 다시 준비할 수 있습니다.

챕터를 이어가기

  1. 공개된 임무를 따라 목표를 완수합니다. 챕터1은 계몽2개를 얻은 뒤 중앙 등불 주임무를 해결합니다.
  2. 완수 후 마지막 꿈에서 남은 피의 유지로 성장한 덱을 정리합니다. 저장 내보내기로 지금 멈춘 상태도 보관할 수 있습니다.
  3. ‘챕터 2 준비 · 장비 교체’를 누르고 보관한 사냥 도구·카릴 문자·화기를 장착하거나 교체합니다. 도구와 문자는 각각2장까지 장착합니다.
  4. 중앙 등불의 시작 칸과 장송의 칼날 면을 다시 선택하고 다음 챕터를 시작합니다. 시작 칸을 고르기 전에는 시작 버튼이 비활성화됩니다. 챕터2에서3으로도 같은 과정을 밟습니다.

성장한12장 덱·소모품·장비·과거 완료 계몽은 보존합니다. 새 챕터의 트랙·시장·적 면/슬롯과 각 덱은 새로 준비합니다. 과거 계몽은 분기를 결정하지만 이번 챕터 계몽 수에는 포함하지 않습니다. 챕터2~3의 지도는 특수 준비17번에 따라4타일을 먼저 연결하고 나머지5타일을 탐험합니다.

첫 이동과 전투

  1. 손패 카드1장을 선택하고 이동을 누릅니다. 밝은 인접 칸이나 열린 출입구를 선택하세요. 새 타일의 회전 방향을 골라 배치한 뒤 연결된 칸으로 진입합니다.
  2. 이동을 마치면 추격을 처리합니다. 여러 경로가 가능하면 사냥꾼에게 가장 불리한 결과가 되는 경로를 고릅니다.
  3. 같은 칸의 적을 고르고 손패 카드·빈 슬롯을 선택해 공격합니다. 공격용 소모품과 보상은 공격을 확정하기 전에 선택합니다.
  4. 공개된 적 행동을 보고 충분한 속도의 빈 슬롯으로 회피하거나 화기를 사용합니다. 단총은 준비 상태에서 기본 공격을 방해합니다.
  5. ‘속도 순서대로 전투 처리’를 누릅니다. 기절·추가 타격·경로 선택이 나타나면 이어서 해결합니다.

후속 임무

챕터2는 소모품을 버려 야수를 유인할 수 있습니다. 최종 처치로 시체 토큰을 얻고 공동묘지에 바쳐 주임무를 진행합니다. 진료소/예배당 피신처는 소모품 수집으로 얻은 생존자를 목적 타일에 인도합니다. 운반 중 순간이동하거나 꿈에 입장하면 이 생존자 토큰을 잃습니다. 시체 토큰은 보존합니다.

대교의 생존자는 떠나기 전에 호위를 선택합니다. 진료소 또는 예배당으로 인도한 결과가 챕터3 분기를 바꿉니다. 챕터3에서는 진료소의 선택, 실험 생존자 포획·인도, 야수 토벌, 이동하는 구원 NPC와 물자 기부를 진행합니다. 표시된 임무 행동에서 실제 소모품과 선택 대상을 고르세요.

챕터2 성직자 야수는2페이즈 전환 뒤 피해를 받지 않으며 지하묘지 진입으로 주임무를 완수합니다. 챕터3은 현재 계몽2개 또는 두 번째 초기화까지 지하묘지 진입이 봉인됩니다. 풀려난 보스의 마지막 처치가 캠페인을 끝냅니다.

안개와 순간이동

안개가 생기면 일반 적과 등불을 제거하고 일반 출현을 막습니다. 안개 안으로 들어갈 수 있지만 꿈 이외의 방법으로 나갈 수 없습니다. 임무를 완수하거나 지정 효과로 안개를 제거하면 등불을 복원합니다. 임무 부활은 실제 처치가 아니므로 유지·처치 효과를 주지 않습니다.

중앙 등불 칸의 상호작용으로 정상 등불 또는 안개 안의 아무 칸을 선택할 수 있습니다. 보상 랜턴은 정상 등불만 사용합니다. 봉인 임무의 진입 금지는 순간이동에도 적용합니다. 호위 생존자의 복귀/놓기를 먼저 처리한 뒤 이동 종료 조건을 확인합니다.

보상16종과 장비

챕터1의 혈석의 파편·랜턴·달·손톱자국·피의 기쁨·눈에 더해 야수의 포효·이오세프카의 수혈액·사자의 선물·형태 없는 오에돈·오에돈의 꿈틀거림·고대 사냥꾼의 유골·이브리에타스의 전조·사형 집행인의 장갑·사냥·정령의 빈 껍데기를 실행합니다.

보상은 사용 후 소진되고 꿈에서 준비합니다. 혈석의 파편은 선택한 슬롯에 계속 적용됩니다. 야수의 포효는 같은 칸 모든 적의 목적지를 각각 선택하며, 전조는 적과 목적지를 함께 선택합니다. 공격 보상은 복수 선택할 수 있습니다. 유골은 회피 가능한 공격에서 스탯 카드나 빈 슬롯 없이 자동 회피합니다. 새 보상 선택이 뜨면 다른 행동 전에 장착·보관을 정리하세요.

타일 효과와 소모품

  • 대성당: 상호작용 치유2.
  • 오에돈 예배당: 적 공격 속도-1. 지정 속도의 전용 능력과 면역이 지정된 임무 적에는 적용하지 않습니다.
  • 대교: 같은 칸 적이 있으면 이동해 나갈 수 없습니다.
  • 지하묘지: 소모품3장 중1장 선택, 나머지는 더미에 섞기.
  • 진료소: 자기 차례 한 번 피해1을 받고 카드1장 뽑기.
  • 성배 교단 예배당의 이름 칸: 소모품1장 교환으로 유지1개 획득(최대3).

예배당에서는 보유품을 교환하거나 ‘소모품 획득 후 교환할 카드 선택’으로 새 카드를 고릅니다. 상자 획득과 교환을 카드1장으로 처리하며 적의 반격을 먼저 받습니다. 골수 가루는 자기 차례에 소진된 장착 도구/문자1장을 준비합니다. 준비된/보관된 보상·혈석의 파편·화기는 대상이 아닙니다. 초대장은 사용자 지시로 제외하고 사냥꾼의 종은1인용에서 사용할 수 없습니다.

꿈과 초기화

처치마다 유지1개를 얻고 최대3개까지 보관합니다. 꿈에서는 유지를 전부 써서 업그레이드를 고르고 기존 카드와 교체하여 덱12장을 유지합니다. 처치당하면 유지를 잃으며 선택해 둔 달이 있으면1개를 보존합니다. 일반 꿈 입장/새 라운드는 트랙을 전진시키지만 챕터 완수 꿈은 트랙을 전진시키지 않습니다.

새 v0.7 사냥의 보스는 초기화 때 현재 칸과 페이즈를 유지하고 치유합니다. 챕터2 카드20/22는 공동묘지 갈색 출현 칸으로 재출현하라는 지시가 우선합니다. 챕터3 카드42는 현재 위치를 유지합니다. 일반 적·소모품과 임무 적 부활 토큰은 해당 초기화 규칙으로 복원합니다.

지도 도식과 점검표

지도20종은 직접 만든 SVG로 표시합니다. 사진과52칸·47출입구·등불7·소모품토큰14·출현17곳의 구조를 대조했습니다. 사진 배경은 사용하지 않습니다. 촬영 원근을 제거한 좌표는 물리 치수/픽셀 완전 일치를 인증하지 않습니다.

Excel 점검표와 텍스트·JSON의 84행은 같은 자료입니다. 구현 상태·검증 근거·직접 점검을 분리하며 사용자 점검은 모두 미점검으로 시작합니다. 직접 확인한 행만 결과와 메모를 기록하세요. 전체 규칙 완성률로 계산하지 않습니다. 상세 대조는 규칙 감사, 실제 실행한 최종 검증은 검증 기록에 있습니다.

남은 구현

성직자 야수·여성 야수 환자·적대 이오세프카 전투는 임시 수치/행동입니다. 실제 양면 카드와 보스 행동 자료를 받으면 교체합니다. 실제 보스 전투를 검증 완료로 표시하지 않습니다. 추가 화기3종은 승인된 단총 임시 효과를 사용합니다.

다른 세 캠페인, 기본판 네 사냥꾼/장치 무기,2~4인 규칙과 온라인 협동, 나머지 보상16종은 미구현입니다. 일부 보상 물건은 원문 자체가 사용불가입니다. 독/발광의 상태 처리와 회복은 있으나 후속 실제 적의 부여 효과는 연결 대상입니다.

별도 임시 시험4종은 새 사냥에서 선택합니다. 이오세프카 치유 시험은 캠페인 적대 NPC와 별개입니다. 원문 JSON/출처/사용자 원본 파일은 보존합니다. 새 ZIP에는 지도 사진20장을 제외하며 다른 카드 사진은 이번 교체 범위 밖입니다.
