기나긴 사냥 챕터 1~3 플레이하기

실제 지도에서 사냥 →

한 명의 사냥꾼으로 기나긴 사냥을 끝까지임무·전투·보상·성장과 챕터 전환을 연결했습니다. 제공된 장치무기 15종 양면과 화기 8종, 실제 성직자 야수·여성 야수 환자·이오세프카 효과를 사용합니다.

실행과 시작 칸

ZIP 전체를 압축 해제하고 hunt.html을 Chrome/Edge로 여세요. 인터넷이나 개발 도구 설치는 필요하지 않습니다. 첫 실행에서 ‘기나긴 사냥 · 챕터 1’을 고르고 장치무기와 시작 면, 중앙 등불의 왼쪽·중앙·오른쪽 칸 중 원하는 곳을 선택합니다. 자동 저장이 있으면 이어서 진행하며 ‘새 사냥’에서 다시 준비할 수 있습니다.

챕터를 이어가기

  1. 공개된 임무를 따라 목표를 완수합니다. 챕터 1은 계몽 2개를 얻은 뒤 중앙 등불 주임무를 해결합니다.
  2. 완수 후 마지막 꿈에서 남은 피의 유지로 성장한 덱을 정리합니다. 저장 내보내기로 지금 멈춘 상태도 보관할 수 있습니다.
  3. 다음 챕터의 ‘준비 · 장비 교체’를 누르고 보관한 사냥 도구·카릴 문자·화기를 장착하거나 교체합니다. 도구와 문자는 각각 2장, 화기는 1개를 장착합니다.
  4. 중앙 등불의 시작 칸과 선택한 장치무기 면을 다시 고르고 다음 챕터를 시작합니다. 시작 칸을 고르기 전에는 시작 버튼이 비활성화됩니다. 챕터 2에서 3으로도 같은 과정을 밟습니다.

성장한 12장 덱·소모품·장비·과거 완료 카드는 보존합니다. 새 챕터의 트랙·시장·적 면/슬롯과 각 덱은 다시 준비합니다. 과거 완료 기록은 분기를 결정하지만 이번 챕터 계몽 수에는 포함하지 않습니다. 챕터 2~3은 특별 준비 17에 따라 4타일을 먼저 연결하고 나머지 5타일을 탐험합니다.

지도 중심 화면

상태와 현재 목표는 위에, 지도와 현재 행동은 중앙에, 손패·무기·화기는 아래에 있습니다. 소모품·보상·일지·적 정보는 상단 버튼으로 여세요. 닫기 또는 Escape로 돌아갑니다. 일지에서 공개된 전체 목표와 이야기를 읽으며 메뉴에서 저장을 관리합니다. 지도 위 칸·출입구·적 토큰을 누르면 대상의 행동과 비용을 확인합니다. 선택만으로 비용을 내거나 다음 타일·적 행동을 공개하지 않습니다.

첫 이동과 전투

  1. 지도에서 인접 칸이나 현재 칸의 출입구를 누르고 손패 카드 1장을 선택합니다. 오른쪽의 이동·탐험 행동을 실행하면 이동 준비와 첫 진입을 함께 처리합니다. 새 타일의 회전 방향을 골라 배치한 뒤 연결된 칸으로 진입합니다.
  2. 이동을 마치면 추격을 처리합니다. 여러 경로가 가능하면 사냥꾼에게 가장 불리한 결과가 되는 경로를 고릅니다.
  3. 같은 칸의 적을 고르고 손패 카드·빈 슬롯을 선택해 공격합니다. 공격용 소모품과 보상은 공격을 확정하기 전에 선택합니다.
  4. 공개된 적 행동을 보고 충분한 속도의 빈 슬롯으로 회피하거나 화기를 사용합니다. 화기는 각 카드의 사용 조건과 준비 비용을 따릅니다.
  5. ‘속도 순서대로 전투 처리’를 누릅니다. 기절·추가 타격·경로 선택이 나타나면 이어서 해결합니다.

필수 보상 획득 선택이 뜨면 먼저 장착·보관을 정리하세요. 선택 중에는 다음 전투나 챕터 준비로 넘어가지 않습니다.

캐릭터와 지도 확대

새로 그린 사냥꾼과 적이 지도에서 대기·걷기·공격·피격·쓰러짐 동작을 보여 줍니다. 공격과 피해는 실제 판정 뒤에 표시합니다. 지도 왼쪽 아래 − / + 또는 Ctrl+휠로 60~180%까지 확대·축소하고, 배율 숫자로 100%로 돌아갑니다. 빈 배경을 드래그해 둘러보며 ‘현재 위치’로 사냥꾼에게 돌아옵니다. 지도에 초점을 두면 + / − / 0을 사용할 수 있습니다.

운영체제의 동작 줄이기 설정을 따릅니다. 무기별 개별 외형은 공통 사냥꾼 동작을 사용합니다. 자세한 조작은 캐릭터·카메라 안내, 대상과 비용 선택은 직접 선택 안내에서 확인하세요.

검증 전용 모드

새 사냥에서 ‘기나긴 사냥 · 검증 전용’을 선택하면 고피해 장치무기와 빠른 지급 프리셋을 사용할 수 있습니다. 회복·손패 보충·6칸 이동 소모품을 제공하며, 시작 보상과 소모품을 직접 선택할 수도 있습니다.

검증 진행은 별도로 저장됩니다. 헤더의 일반·검증 이어하기 버튼으로 각각 재개하세요. 화면과 저장파일에 검증 표시가 남으며, 검증 장비를 사용한 결과는 정규 플레이 기록과 별도로 관리합니다.

이야기와 임무 기록

도입부와 공개된 임무의 이야기를 게임 안에서 텍스트로 읽습니다. 글자 크기를 100~150%로 조절할 수 있습니다. 별도 이야기가 없는 카드는 공개된 임무 기록을 표시합니다. 사진 확대나 원본 자료실로 이동할 필요가 없습니다.

임무 진행

현재 공개된 카드의 이야기와 지시를 읽고 목표를 진행하세요. 아직 공개되지 않은 후속 임무의 내용·보상·분기는 목표 요약에 표시하지 않습니다.

같은 예배당 도착에서 호위 완료와 장소 사건이 겹치면 호위 완료를 먼저 처리합니다. 화면에서 처리 순서를 선택할 필요 없이 이어서 진행됩니다.

안개와 순간이동

안개가 생기면 일반 적과 등불을 제거하고 일반 출현을 막습니다. 안개 안으로 들어갈 수 있지만 꿈 이외의 방법으로 나갈 수 없습니다. 임무를 완수하거나 지정 효과로 안개를 제거하면 등불을 복원합니다. 임무 부활은 실제 처치가 아니므로 유지·처치 효과를 주지 않습니다.

중앙 등불 칸의 상호작용으로 정상 등불 또는 안개 안의 아무 칸을 선택할 수 있습니다. 보상 랜턴은 현재 이동 가능한 정상 등불만 보여 주며 목적지가 없으면 사용할 수 없습니다. 봉인 임무의 진입 금지는 순간이동에도 적용합니다. 운반 토큰은 해당 임무의 복귀/놓기 규칙을 따릅니다.

보상과 장비

보상 32종 중 30종의 효과를 실행합니다. 작은 오르골·의식용 재료는 카드에 인쇄된 사용불가 임무 물품으로 보관합니다. 기나긴 사냥에서는 실제 캠페인 카드가 주는 보상 16종을 획득합니다. 다른 보상을 따로 확인하려면 전투 연습의 시작 보상 선택을 사용하세요.

소진하는 보상은 사용 후 꿈에서 준비합니다. 지속 혈석은 선택한 슬롯에 계속 적용되고 변형으로 슬롯이 줄면 적용 슬롯을 다시 고릅니다. 야수의 포효는 같은 칸 모든 적의 목적지를 각각 선택하며 전조는 적과 목적지를 함께 선택합니다. 공격 보상은 복수 선택할 수 있습니다. 유골은 회피 가능한 공격에서 스탯 카드나 빈 슬롯 없이 자동 회피합니다. 챕터당 1회 효과는 꿈이나 골수 가루로 횟수가 돌아오지 않습니다.

타일 효과와 소모품

  • 대성당: 상호작용 치유 2.
  • 오에돈 예배당: 적 공격 속도 -1. 지정 속도의 전용 능력과 면역이 지정된 임무 적에는 적용하지 않습니다.
  • 대교: 같은 칸 적이 있으면 이동해 나갈 수 없습니다.
  • 지하묘지: 소모품 3장 중 1장 선택, 나머지는 더미에 섞기.
  • 진료소: 자기 차례 한 번 피해 1을 받고 카드 1장 뽑기.
  • 성배 교단 예배당의 이름 칸: 소모품 1장 교환으로 유지 1개 획득(최대 3).

예배당에서는 보유품을 교환하거나 ‘소모품 획득 후 교환할 카드 선택’으로 새 카드를 고릅니다. 상자 획득과 교환을 카드 1장으로 처리하며 적의 반격을 먼저 받습니다. 골수 가루는 자기 차례에 소진된 장착 비지속 도구/문자 1장을 준비합니다. 준비된/보관된 보상·지속 혈석·화기는 대상이 아닙니다. 초대장은 사용자 지시로 제외하고 사냥꾼의 종은 1인용에서 사용할 수 없습니다.

꿈과 초기화

처치마다 유지 1개를 얻고 최대 3개까지 보관합니다. 꿈에서는 유지를 전부 써서 업그레이드를 고르고 기존 카드와 교체하여 덱 12장을 유지합니다. 처치당하면 유지를 잃으며 선택해 둔 달이 있으면 1개를 보존합니다. 일반 꿈 입장/새 라운드는 트랙을 전진시키지만 챕터 완수 꿈은 트랙을 전진시키지 않습니다.

보스는 일반 초기화 때 현재 칸과 페이즈를 유지하고 치유합니다. 챕터 2 카드 20/22는 공동묘지 붉은 갈색 출현 칸으로 재출현하라는 지시가 우선합니다. 챕터 3 카드 42는 현재 위치를 유지합니다. 일반 적·소모품과 임무 적 부활 토큰은 해당 초기화 규칙으로 복원합니다.

지도 도식과 점검표

지도 20종은 직접 만든 SVG로 표시합니다. 사진과 52칸·47출입구·등불 7·소모품 위치 12/토큰 14·출현 17곳의 구조를 대조했습니다. 사진 배경은 사용하지 않습니다. 촬영 원근을 제거한 좌표는 물리 치수/픽셀 일치 인증은 아닙니다.

Excel 점검표와 텍스트·JSON은 동일 항목을 담습니다. 구현 상태·검증 근거·사용자 직접 점검을 구분합니다. 직접 점검란은 개인 확인용이고 전체 규칙 완성률로 계산하지 않습니다. 51번 연구와52번 진료소 피신처의 정상 완료·보상 경로를 추가 확인했습니다. 상세 대조는 규칙 감사, 이번 표시 개편의 실제 검사는 검증 기록에 있습니다.

저장과 다른 화면

각 행동 뒤 자동 저장합니다. 기존 v0.7 저장 공간과 이전 v0.6/v0.5 자동 저장을 유지합니다. 규칙11을 포함한 과거 명령은 저장 당시 규칙으로 재생하며 자동 저장 키와 JSON 형식을 유지합니다. 중요한 진행은 ‘저장 내보내기’로 JSON을 보관하고 폴더/브라우저 이동이나 캐시 삭제 전에 내보내세요.

현재 범위와 자료

현재 목표는 한 캠페인을 한 명의 사냥꾼으로 진행하는 것입니다. 다른 캠페인과 다인/온라인 협동은 이후 검토할 범위입니다. 지금 기나긴 사냥 진행에 추가로 요청하는 자료는 없습니다. 제공된 카드와 무기·화기·보상의 지원 및 실제 검증 범위는 점검표와 검증 기록에서 확인할 수 있습니다.

기존 저장과 별도 임시 시험은 당시 효과를 유지합니다. 현재 실제 구성품으로 처음부터 플레이하려면 새 사냥을 시작하세요. 원문 JSON의 수신 당시 상태와 임시 정책은 출처 기록이며 현재 지원 범위를 뜻하지 않습니다. 사용자의 원본 파일은 보존하고 배포에는 제공된 사진을 제외합니다. 이야기·적·보상은 텍스트로 표시하며 제공된 사진은 게임 화면과 배포 ZIP에서 제외합니다. 원본 파일은 개발 참고용으로 보존합니다.
