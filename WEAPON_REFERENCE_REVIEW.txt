현재 연결된 원본
장치무기 15종의 30개 형태를 연결합니다. 제공된 무기 사진의 인물 부분 28개와 실제 게임 영상에서 확보한 장송의 칼날 정지 캡처 두 개를 사용합니다.
원본의 정수 크롭을 유지하고 배경·문자·장식 테두리는 alpha로 분리합니다. 남겨진 RGB를 보존하며 없는 포즈·몸·무기·변형 프레임을 새로 그리지 않습니다.
이전 v0.8.3의 생성형 720프레임 제작 기록은 work/qa에 보존합니다. 현행 원본 픽셀 자산의 확보 수량이나 원작 동작 수량으로 계산하지 않습니다.

실제 원본과 검토 범위
제공 무기 사진의 복장·모자·망토·장화·손·들고 있는 무기를 외형 기준으로 삼습니다. 두 형태의 원근·촬영 노출 차이도 원본에 남아 있습니다.
장송의 칼날은 Sykioh 실제 게임 녹화의 13:20과 14:36 대표 화면을 사용합니다. 첫 화면은 곡검을 든 사냥꾼이 앞을 향하고, 두 번째는 변형 뒤 긴 무기를 든 사냥꾼의 등이 보입니다. 영상 전체를 연속으로 시청했다고 기록하지 않습니다.
https://www.youtube.com/watch?v=dnF4F7Agxo0
두 장송 원본은 실제 동작 사이에 잡힌 한 자세입니다. 곡검 화면의 신발 하단 일부가 영상 경계에서 잘렸으며, 변형 뒤 낫의 전체 칼날은 어두운 배경과 겹쳐 분명하게 드러나지 않습니다. 원본 방향 차이와 보이지 않는 부분을 그대로 기록합니다.

무기 형태의 해석
지팡이·채찍, 짧은 도끼·긴 도끼, 소검·대검, 소검·돌망치, 단검·쌍검, 곡검·낫의 차이는 실제 원본 외형을 사용합니다.
보드게임의 내부 면 번호가 원작 일반형·변형형의 순서와 항상 같지는 않습니다. 일반 성검과 이질적인 성검의 순서도 서로 다르며, 이질적인 성검을 별도의 무기 조립 기계나 월광검으로 만들지 않습니다.
야수의 발톱은 제공 사진의 쌍발톱·단일 발톱 상태를 따릅니다. 전신을 새 야수로 바꾸지 않습니다.
토니트루스는 실제 충전 효과에 따라 전기 외형을 사용합니다. 양쪽 규칙 구성에서 모두 충전할 수 있으므로 내부 면 번호만으로 결정하지 않습니다.
현재 사진 속 보조 화기와 복장은 외형에 고정됩니다. 실제 장착 화기의 사용 효과·준비 조건은 바뀌지만 사진의 왼손 화기를 다른 총으로 다시 그리지 않았습니다.

공격 효과와 원작 동작의 구분
인쇄된 85개 장치무기 공격 슬롯을 표시 효과에 연결합니다. 실제 판정 뒤 선택한 무기 형태·슬롯의 베기·찌르기·발톱·폭파·사격 효과를 표시합니다.
레이테르팔라슈의 수은탄 사격 슬롯은 총검 공격으로 구별합니다. 별도 화기·소모품을 이 장치무기 공격으로 추측하지 않습니다.
현재 무기의 원작 연속 공격·걷기·피격·사망·변형 동작 은행은 0개입니다. 각 형태는 원본 정지 자세 하나이며, 효과의 속도 조절이나 위치 이동을 원작 콤보로 부르지 않습니다.
속도·피해·효과·변형 비용·정보 공개·강제 이동·임무 진행은 기존 보드게임 규칙 엔진을 유지합니다. 원작의 실시간 체력 감소·양손 화기 제한·초 단위 버프 만료를 새 규칙으로 추가하지 않습니다.

원본 보존의 의미와 한계
RGB 보존 검증은 선택한 정수 크롭과 해당 표시 영역의 실제 원본 픽셀을 비교하는 것입니다. 사진에서 이미 잘린 창끝·깃털·검끝·자루, 원본에 숨은 몸, 조명 때문에 보이지 않는 세부사항을 복원했다는 검증이 아닙니다.
원작 3D 메시·리그·애니메이션 데이터를 추출하지 않았습니다. 기술적 조사 기록과 실제 데이터 추출·변환은 구분합니다.
다운로드가 막힌 자료는 링크를 제공하고 사용자가 참고자료에 넣어 준 로컬 파일을 확인합니다. 차단된 다운로드를 우회하거나 반복하지 않습니다.
