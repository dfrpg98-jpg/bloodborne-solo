Phaser 표시 엔진과 카메라 / v0.8.2 / 2026-10-12

Phaser 4.2.1의 공식 npm 실행 파일과 MIT 라이선스를 assets/vendor에 포함합니다. 원본 배포·무결성은 phaser-provenance.json에 기록했습니다. 추가 설치와 CDN 연결은 필요 없습니다.

규칙과 표시
hunt-engine.js가 규칙, 상태, 공개 순서, 명령 기록과 저장 검증을 계속 담당합니다. 이번 변경은 이 규칙 엔진을 수정하지 않습니다.
hunt-animation-events.js는 전후의 공개 인물·체력·위치·이미 표시된 사건을 대조해 처리된 이동·공격·발사만 구분합니다. 다음 적 행동이나 임무·덱 순서를 읽지 않습니다.
hunt-presentation.js에는 공개 인물의 좌표·유형·현재 체력·선택 표시, 실제 처리된 표시 행동과 진행 번호만 전달합니다. 규칙 상태 전체, 명령 객체, 덱, 미래 임무, 보상과 저장 데이터는 전달하지 않습니다.
새로운 투명 PNG 5종의 80프레임을 Phaser Sprite/Animation으로 재생합니다. 실물 사진은 사용하지 않았으며 각 프레임의 발 기준점을 맞춘 atlas metadata를 별도로 작성했습니다. 원본 생성 PNG의 픽셀을 변경하지 않았습니다.
대기·이동·공격·피격·쓰러짐과 화기 표시를 연결했습니다. 공격 준비만으로 타격을 표시하지 않으며 실제 피해가 확인되어야 피격을 재생합니다. 임무 제거·꿈 복귀·초기화는 사망을 추측하지 않습니다.
창 크기 변경·스크롤·줌에는 위치만 보정하고 이동 동작을 만들어 내지 않습니다. 빠른 다음 행동·저장 복원·장면 변경은 이전 연출 예약을 취소합니다. 운영체제의 동작 줄이기 설정을 따릅니다.

지도 카메라
hunt-camera.js는 DOM 지도 배율과 스크롤을 함께 관리합니다. 기존 칸·출입구·적 버튼의 좌표계를 그대로 확대하고, 같은 화면 좌표를 Phaser에 전달합니다.
지도의 양쪽 여백을 더해 가장자리 칸도 화면 중앙에 놓을 수 있습니다. 가장자리 여백은 캐릭터의 월드 좌표에 섞이지 않게 보정합니다. 캔버스는 지도 client box에 맞추며 스크롤바와 경계선은 제외합니다.
60~180% 줌, 포인터 중심 Ctrl/Meta+휠, 빈 배경 드래그, 배율 초기화, 맞춤, 현재 위치 따라가기를 제공합니다. 카메라는 엔진과 저장을 호출하지 않습니다.
표시 캔버스는 클릭을 받지 않으며 기존 지도 버튼이 입력을 맡습니다. 로딩·부분 이미지 실패·Phaser 오류 시 기본 표식과 조작을 유지합니다.

범위와 실행 확인
현재 HUD와 SVG 지도를 유지한 2D 표시 계층입니다. 전체 지도를 Phaser Scene으로 바꾸거나 규칙 코드를 이식할 필요는 없다고 판단했습니다. Unity/Godot 설치는 이번 기능에 필요하지 않습니다.
공통 인물 유형을 사용하며 모든 장치무기·적의 개별 외형은 후속 작업입니다. 직접 file:// 주소를 여는 브라우저 검사는 도구의 URL 정책에 막혀 수행하지 못했습니다. inline atlas metadata와 native Image 로더를 사용해 JSON XHR 의존을 제거했지만, 실제 화면 검증은 localhost 환경을 대상으로 했습니다.
