현재 실행
../../hunt.html에서 한 명의 사냥꾼으로 챕터 1~3을 진행합니다. 번호 카드 1~60의 조건부 공개·계몽·임무 곁가지·보스/NPC·챕터 전환을 실제 지도·전투·성장과 연결했습니다.
제공된 장치무기 15종 양면, 화기 8종, 보상 정의 32종을 지원합니다. 보상은 30종 사용 효과와 2종 사용불가 임무 물품으로 구분합니다. 이 캠페인의 카드가 주는 보상 16종을 획득합니다.
성직자 야수는 사용자 전사한 1인 체력 10/8과 양 페이즈 각 5장 행동 덱을, 여성 야수 환자와 이오세프카는 참고자료 카드 효과를 적용합니다. 새 사냥은 규칙 11입니다.
현재 기나긴 사냥 진행을 위해 추가로 요청하는 자료는 없습니다. 다른 캠페인과 다인/온라인 협동은 사용자가 이후에 검토하기로 정한 범위입니다.
../../guide.html의 플레이 안내와 ../../RULES_AUDIT.txt의 규칙 대조를 참고하세요. 이번 버전의 실제 검증 결과는 ../../VERIFICATION.txt에 기록합니다.

번호 카드는 촬영된 면에 번호가 없어 사용자가 지정한 파일명 오름차순으로 번호를 부여했습니다.
챕터 3은 임무(20261011_123710.jpg), 준비(20261011_123714.jpg) 순으로 촬영했습니다.

A/B는 각 적의 촬영 파일명 순서로 붙인 구분이며 공식 면 명칭이 아닙니다.
20261011_142042.zip의 JPG 20개: 명칭 있는 지도 타일 13개와 명칭 없는 7개. 사진의 52칸·내부 인접·출입구·기호·인쇄 효과를 기록했습니다.
각 원본 항목의 파일명·SHA-256을 보존합니다. 자료실의 축소 카드 사진과 원본 파일의 해시는 다릅니다.

파일과 수신 당시 상태
data.json / data.js: 캠페인 카드, 일반 적 양면, 지도 구조, 명칭 연결, 출처, 사용자 확인 기록과 자료 수집 당시의 상태.
images/: 캠페인/적 카드 축소 사진, 기호 예시와 명칭 확대 자료. 배포에서는 지도 사진 20장을 제외하며 ../../assets/tiles/의 직접 제작 SVG를 사용합니다. 사용자의 원본 사진은 삭제하지 않습니다.
../../campaign.html: 원문 카드 자료실. 아직 게임에서 공개하지 않은 이야기와 결과도 포함합니다.
원본 데이터의 automated=false, runtime=reference 및 임시 정책/추가 자료 표시는 자료 수신 시점의 기록입니다. 이후 받은 자료와 실행 모듈로 구현한 현재 지원 범위를 뜻하지 않습니다.
원문과 출처를 수정해 당시 상태를 지우지 않습니다. 현재 실행은 chapter/mission/hunt/weapon/firearm/reward 전용 모듈과 최신 점검표를 기준으로 확인합니다.
과거 임시 구성품 시험과 이전 저장 재생도 별도로 보존하며 정규 새 사냥은 실제 효과를 사용합니다.

전사 기준
규칙 문구의 줄바꿈/일부 공백을 정리하고 아이콘은 대괄호 이름으로 바꿨습니다. 공격 속도는 1~3, 혈액방울은 피해로 기록합니다.
전체 서사는 사진에 보존했으며 모든 이야기 문장을 텍스트로 옮긴 것은 아닙니다. 게임에서는 도입부와 실제 공개된 카드만 열람합니다.
reveal은 공개 대상 참조 목록입니다. 실행 시점·선택·조건을 함께 읽고 모든 대상을 즉시 공개하지 않습니다.
checksCards는 보유한 완료/결과 카드와 연결합니다. 현재 챕터 계몽 수와 과거 완료 기록을 구분합니다. 특별 준비 17과 재사용 카드도 같은 번호로 참조합니다.
카드 39/56은 도착 시 이미 보유한 결과 기록으로 분기를 먼저 판정하는 현재 해석을 사용합니다. 규칙서/FAQ의 추가 제작사 판정으로 주장하지 않으며 상세 경계는 ../../RULES_AUDIT.txt에 있습니다.

원문은 유지하고 enemyNameAliases에서 huntsmans-minion으로 연결합니다. 판독·명칭 관련 미해결 질문은 없습니다.
일반 적 피규어는 종류별 4개로 사용자 확인을 miniatureCount/miniatureCountSource에 보존합니다.

일반 적 판독 요약 (속도/피해)
야수 사냥 무리: 체력 4, 기본 도끼 휘두르기 2/2.
 A: 방패 치기 2/2, 방해·기절 / 발광한 무리.
 B: 소총 사격 1/4, 기절 / 화염병 투척.
재앙의 야수: 체력 4, 기본 재빠른 휩쓸기 3/2, 활성화·추격 이동 2칸.
 A: 달려들어 뜯기 1/4, 기절·회피 불가 / 야수의 포효.
 B: 다단 가르기 2/2, 첫 공격 회피·방해 후에도 회피 또는 추가 피해 2 / 날것 그대로의 분노.
야수 사냥 하인: 체력 5, 기본 느릿느릿한 휘두르기 1/3.
 A: 벽돌 휩쓸기 3/2, 방해 / 어깨 돌진.
 B: 내려찍기 1/4, 방해 불가·같은 칸의 다른 사냥꾼에게도 효과 / 벽돌 후려갈기기.
전체 문구와 조건은 data.json과 원문 카드 자료를 참조하며 실제 처리에는 공통 규칙을 적용합니다.

지도와 챕터 준비
tiles의 source/image/spaces/adjacency/exits/rules는 사진에서 읽은 자료입니다. placeName은 실제 이름이 인쇄된 칸이며 타일 전체 이름과 구분합니다.
N/E/S/W는 사진 기준 방향이고 배치 회전에 따라 변환합니다. 인접은 무방향 연결입니다. 등불은 적 출현 기호가 아닙니다.
금색/붉은 갈색/보라색 출현 기호로 적 슬롯을 구분합니다. 구조는 52칸·47출입구·등불 7·소모품 위치 12/토큰 14·출현 17입니다.
마당 등불은 실물 사진의 W/E/S 3출입구를 유지하고 규칙서 예시의 N을 추가하지 않습니다. 촬영 원근을 제거한 경계 좌표는 근사 전사이며 픽셀·물리 치수 일치 인증은 아닙니다.
규칙서 10·25쪽: 매 챕터 적 종류별 면을 무작위 선택하고 카드 3장을 섞어 슬롯에 놓습니다. 같은 종류의 피규어는 그 면을 공유합니다. 지도 초기화/전투마다 다시 뽑지 않습니다.
슬롯은 출현 기호와 활성화 순서를 정합니다. 피규어가 모두 사용 중이면 가장 먼 해당 일반 적을 가져오고 별도 임무 지시는 우선합니다.
매 챕터 중앙 등불의 원하는 시작 칸을 고릅니다. 챕터 2~3은 준비 17에 따라 4타일을 선배치하고 나머지 5타일을 탐험합니다.
