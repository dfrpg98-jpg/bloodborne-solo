블러드본 보드게임 · 1인용 개발판 v0.6.2

실행
1. ZIP 전체를 압축 해제합니다.
2. bloodborne-solo 폴더의 hunt.html을 Chrome 또는 Edge로 엽니다.
   index.html로 열었다면 상단의 ‘실제 지도에서 사냥 →’을 누르세요.
3. 인터넷, Python, Node.js 설치 없이 플레이할 수 있습니다.
4. 첫 실행에서는 시작 설정을 먼저 고릅니다. ‘기나긴 사냥 · 챕터 1’을 선택하고
   중앙 등불 타일의 왼쪽/중앙/오른쪽 칸을 도식에서 골라 ‘새 사냥 시작’을 누릅니다.
   기존 정상 자동 저장이 있으면 이어서 플레이합니다. ‘새 사냥’에서 다시 준비할 수 있습니다.
5. 임무 패널을 보며 계몽 임무 2개를 완수하고 중앙 등불로 돌아오세요.
6. 챕터를 완수하면 마지막 꿈에서 유지를 쓰고 ‘저장 내보내기’로 진행을 보관하세요.

v0.6.2 변경
- 성배 교단 예배당의 명명 칸에서 보유 소모품 1장을 버려 피의 유지 1개를 얻습니다(최대 3개).
- 상자 획득을 함께 고르면 카드 1장으로 반격·획득·교환을 처리합니다.
- ‘소모품 획득 후 교환할 카드 선택’을 고르면 방금 얻은 카드도 교환할 수 있습니다. 추가 스탯 비용 없이 선택하거나 교환을 마칩니다.
- 기나긴 사냥의 자기 차례에 골수 가루를 선택하고 소진된 장착 보상 1장을 준비합니다. 골수 가루만 버립니다.
- 준비된/보관된 보상, 혈석의 파편과 화기는 골수 가루 대상이 아닙니다. 대상이 없으면 소비하지 않습니다.
- 기존 v0.6.1에서 얻은 골수 가루도 같은 인스턴스로 사용할 수 있습니다.

규칙 구현 점검표
- RULES_CHECKLIST.txt는 65개 확인 조건을 읽는 표이고 RULES_CHECKLIST.json은 같은 내용의 원본 데이터입니다.
- RULES_CHECKLIST.xlsx는 Excel 점검표입니다. 구현 상태, 검증 근거 수준, 사용자 직접 점검을 각각 구분하며 노란색 열에 결과와 메모를 기록할 수 있습니다.
- 직접 점검은 ‘미점검’에서 시작합니다. 실제로 확인한 행만 결과를 기록하세요.
- 구현 상태가 ‘구현’이어도 전용 테스트가 부족한 행은 검증 근거 수준에 별도 표시합니다.
- 부분·미구현·범위 제외를 섞어 전체 규칙 완성률로 계산하지 않습니다.
- RULES_AUDIT.txt는 세부 감사, VERIFICATION.txt는 최종 버전의 실제 검증 기록입니다.

v0.6.1에서 유지한 지도·시작 선택 개선
- 지도 20종을 직접 그린 SVG 도식으로 교체했습니다. 칸 경계·출입구·등불·소모품·적 출현 기호를 표시합니다.
- 실제 지도, 새 타일 배치 미리보기, 타일 자료실에서 같은 도식을 사용합니다.
- 사진과 칸 연결·출입구 소속/방향·기호칸/수량을 대조했습니다. 사진 배경은 사용하지 않습니다.
- 새 배포 ZIP에서 지도 사진 20장을 제외했습니다. 기존 프로젝트의 원본 자료는 보존합니다.
- 원근을 제거한 도식이므로 사진 픽셀이나 물리적 치수의 완전 일치를 뜻하지 않습니다.
- 첫 실행 시작 칸 선택을 먼저 표시합니다. 시작 칸 선택값은 저장에도 남습니다.
- 중앙 등불 상호작용으로 정상 등불 또는 안개 안의 아무 칸에 순간이동할 수 있습니다.
- 폐가에서 소모품과 ‘생존자 구조도 함께 선택’을 골라 카드 1장으로 함께 상호작용할 수 있습니다.
- 규칙서 전체 검토와 남은 기능은 RULES_AUDIT.txt, 최종 검증 결과는 VERIFICATION.txt에 기록했습니다.

현재 구현: 기나긴 사냥 챕터 1
- 카드 1~16의 조건부 공개, 계몽 임무, 생존자 호위·도주와 구조 결과 분기를 처리합니다.
- 안개 진입로, 파괴된 등불, 임무 적 부활 토큰과 초기화, 임무 완수 시 복원을 처리합니다.
- 계몽 2장 이후 중앙 등불 우두머리와 챕터 승리, 마지막 꿈의 성장·회복을 연결했습니다.
- 보상 카드 6종(혈석의 파편·랜턴·카릴 문자 달/손톱자국/피의 기쁨/눈)과 루드비히의 장총을 획득합니다.
- 보상 장착·보관, 파편 슬롯, 사용·소진·꿈 회복과 화기 장착을 선택할 수 있습니다.
- 실제 타일에서 스탯 카드를 써서 이동·탐험하고, 이동을 마치면 적이 추격합니다.
- 차례 종료 후 사냥 보드 순서로 적이 활성화합니다. 재앙의 야수는 2칸 이동합니다.
- 야수 사냥 무리·야수 사냥 하인·재앙의 야수의 양면 공격과 전용 능력을 처리합니다.
- 추가 행동 공개, 지정 속도의 능력, 다단 가르기, 방해·기절·회피 제한을 구분합니다.
- 단총은 기본 공격에만 사용합니다. 장착 화기·준비 여부·효과를 상단에 표시합니다.
- 기본 스탯 12장과 실제 업그레이드 20종×3장=60장을 사용합니다.
- 꿈에서 피의 유지로 카드를 고르고, 기존 카드와 교체하여 12장을 유지합니다.
- 피규어는 종류별 4개. 공급이 부족하면 가장 먼 피규어를 재사용합니다.
- 지도 초기화는 적·소모품을 복원합니다. 적 면·마커 배정과 적 행동 덱은 유지합니다.

첫 플레이
- 아래 손패에서 카드 1장을 선택 → ‘이동’ → 지도에서 밝은 칸이나 열린 출입구 선택.
- 새 타일이 공개되면 회전 방향을 선택하고 배치합니다. 이어진 칸으로 진입합니다.
- 같은 칸의 적을 대상으로 선택 → 카드와 빈 공격 슬롯 선택 → ‘공격’.
- 적 행동을 본 뒤 필요한 경우 회피 카드와 빈 슬롯을 고르거나 화기를 사용합니다.
- 회피를 골랐어도 ‘속도 순서대로 전투 처리’를 눌러야 나머지 전투가 진행됩니다.
- 차례를 마치면 적 활성화 후 다음 라운드의 손패를 보충합니다.
- 적 이동 경로·활성화·피규어 동률 등 선택이 뜨면 표시된 설명에 따라 고르세요.

임시 구성물 시험
- ‘새 사냥’에서 임시 성직자 야수 2페이즈, 여성 야수 환자 A, 여성 야수 환자 B, 이오세프카 시험을 선택합니다.
- 이오세프카 시험은 중앙 등불 칸에서 카드 1장을 써서 치유 2를 하는 상호작용입니다.
- 사용자 요청으로 작성한 임시 수치·효과이며 실물 카드 전사가 아닙니다.
- temporary-components.js에 원문 자료와 별도로 보관하고 추후 실물 자료를 받으면 교체합니다.
- 시험 완료는 기나긴 사냥 챕터 2~3의 완료와 별개입니다.

현재 범위
- 제공 자료대로 진행하는 캠페인은 기나긴 사냥 챕터 1입니다. 챕터 2~3 임무·준비·자동 전환과 챕터 사이 장비 교체는 미구현입니다.
- 다른 세 캠페인과 2~4인 게임 규칙/온라인 협동은 미구현입니다.
- 선택 가능한 실제 장치 무기는 장송의 칼날뿐입니다. 기본판의 네 사냥꾼/장치 무기는 연결되지 않았습니다.
- 챕터 1 완료 시 성장·소모품·보상·화기·완료 계몽 카드를 저장해 후속 구현으로 전달합니다.
- 대성당·오에돈 예배당·대교·지하묘지·진료소와 중앙 등불의 등불/안개 안 이동을 처리합니다.
- 성배 교단 예배당의 소모품 교환을 처리합니다. 보유품 교환과 상자 획득 후 선택을 지원합니다.
- 초대장 제외 소모품 덱은 36장/18종이며 기나긴 사냥에서 17종 효과를 실행합니다. 보상이 없는 훈련/독립 지도 연습은 골수 가루를 사용할 수 없고, 사냥꾼의 종은 다른 사냥꾼이 없어 1인용에서 쓸 수 없습니다.
- 사용자 제공 보상 32종 중 챕터 1의 6종을 실행합니다. 나머지 26종은 자료 등록 범위이고 일부는 원문에서 사용불가인 임무 물건입니다.
- 루드비히의 장총·교단의 연발총·화염방사기는 사용자 요청대로 단총과 같은 임시 능력을 사용합니다.
- 임시 성직자 야수 시험은 페이즈 전환을 제공하지만 실제 보스의 페이즈별 독립 행동 덱은 미구현입니다.
- 임시 이오세프카는 치유 상호작용 시험이며 실제 적대 NPC 규칙은 미구현입니다.
- 독/발광의 피해·해제·꿈 회복 상태는 있지만 후속 실제 적의 상태 부여는 미연결입니다.
- 임무 없는 ‘실제 지도 전투 연습’은 이전 v0.5의 전투·성장 플레이를 유지합니다.

저장
- 매 행동 후 현재 브라우저에 자동 저장합니다. 중요한 진행은 ‘저장 내보내기’로 보관하세요.
- v0.6 자동 저장은 bloodborne-hunt-v06을 사용하고 이전 bloodborne-hunt-v05 저장은 유지합니다.
- 같은 브라우저에 이전 저장이 있으면 ‘이 브라우저의 v0.5 사냥 불러오기’ 버튼이 표시됩니다.
- v0.5 JSON도 ‘불러오기’로 열 수 있으며, 임무 없는 전투 연습 모드로 이어집니다.
- hunt.html / index.html / chapter.html의 저장은 서로 독립적입니다.
- 실제 지도 저장은 hunt.html에서, 기존 훈련 저장은 index.html에서 불러옵니다.
- 이전 v0.3~0.4 훈련 저장과 지도 검증 저장은 각각의 이전 화면에서 계속 사용할 수 있습니다.
- 폴더 이동, 브라우저 변경, 캐시 삭제 전에는 JSON으로 내보내세요.
- 새 사냥에서는 시드, 시작 칸, 장송의 칼날 형태, 화기를 고릅니다.
- 선택적 시작 소모품은 테스트용 지급입니다. 기본값 ‘없음’이 정규 시작입니다.

자료와 개발
campaign.html: 도입부·챕터·카드·적 자료와 타일 도식
components.html: 기본/업그레이드 스탯·소모품·보상 목록과 구현 상태
assets/tiles/index.html: 20개 지도 도식 전체 목록
guide.html: 사용 안내
DEVELOPMENT.md: 구조, 규칙 처리 기준과 다음 단계
VERIFICATION.txt: 이번 버전의 검증 결과
RULES_CHECKLIST.txt / RULES_CHECKLIST.json: 행별 규칙 구현 점검표
사용자 제공 한국어 규칙서의 전체 쪽과 제공 캠페인/카드 자료를 대조했습니다.
원문 JSON/출처 기록은 보존합니다. 새 배포에는 지도 타일 사진을 넣지 않으며, 원본 제공 자료는 기존 Desktop 폴더에 남습니다.
이번 교체는 지도 사진에 적용합니다. 임무·적·보상 카드 사진은 별도 자료로 남아 있습니다.
Node.js가 있는 개발 환경에서는 npm test로 규칙 검증을 실행할 수 있습니다.
