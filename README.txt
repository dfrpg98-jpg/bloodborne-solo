블러드본 보드게임 · 1인용 개발판 v0.7.1

실행
1. ZIP 전체를 압축 해제하고 bloodborne-solo 폴더의 hunt.html을 Chrome/Edge로 엽니다.
2. 첫 실행에서 ‘기나긴 사냥 · 챕터 1’을 고르고 중앙 등불의 왼쪽/중앙/오른쪽 칸을 선택합니다.
3. 공개된 임무를 따라 진행하고 챕터를 완수하면 마지막 꿈에서 남은 유지로 성장을 정리합니다.
4. ‘챕터 2 준비 · 장비 교체’를 눌러 보관한 도구·문자·화기를 교체합니다.
5. 다음 챕터의 중앙 등불 시작 칸과 장송의 칼날 면을 고르고 시작합니다. 챕터 2→3도 같습니다.
6. 중요한 진행은 ‘저장 내보내기’로 JSON 파일을 보관하세요. 인터넷/개발 도구 설치 없이 실행합니다.

v0.7.1 변경
- 캠페인 새 사냥 준비에서 도입부를 읽습니다. 게임의 ‘도입부 · 임무 이야기’에서 새 공개 카드와 지난 챕터에 실제 공개했던 이야기를 다시 읽습니다.
- 임무 60장의 서사는 제공된 원문 카드 이미지로 열람합니다. 확대/축소·앞뒤 이동을 지원하며 미공개 카드의 제목과 내용은 표시하지 않습니다. 이야기 열람은 게임 진행·명령 로그를 바꾸지 않습니다.
- 새 사냥은 마지막 탐험 타일도 모든 출입구를 봉쇄하는 배치를 허용하지 않습니다. 적합한 대체가 없으면 카드·이동 상태를 그대로 두고 거절합니다.
- 독·발광 공격 키워드의 상태 부여를 회피/취소/면역/마비 안개와 연결합니다. 새로 얻은 발광은 이후 타격부터 적용합니다. 실제 이오세프카·여성 야수 환자의 독 공격과 시험용 발광 공격을 각각 검증합니다.
- 새 사냥에서 같은 칸 여러 적의 상호작용 반격 순서를 직접 고릅니다. 경로/활성화/피규어/반격 순서에서 가장 불리한 결과를 고르도록 안내합니다. 불리함 판단은 사용자가 합니다.
- 규칙 버전9를 새 사냥에 적용하고 기존8/7/무버전 저장의 명령은 원래 규칙으로 재생합니다. 저장 형식과 v07 자동 저장 키는 유지합니다.

v0.7.0에서 유지한 기능
- 기나긴 사냥 카드1~60의 챕터1~3 준비·조건부 임무·전환·최종 캠페인 승리를 연결합니다.
- 매 챕터마다 시작 칸을 새로 선택합니다. 고르기 전에는 다음 챕터 시작 버튼이 활성화되지 않습니다.
- 챕터2~3은 특수 준비17번에 따라 중앙 등불/공동묘지/연결 타일/지하묘지를 선배치합니다. 1인용은 선배치4타일과 더미5타일, 총9타일입니다.
- 성장한12장 덱·소모품·보상·화기·완료 계몽을 이어받습니다. 트랙·시장·덱과 적 면/슬롯은 새로 준비하며 지난 계몽을 이번 챕터 계몽에 더하지 않습니다.
- 시체 봉헌, 피신처의 생존자 운반, 환자/대교 하인 부활, 호위 분기, 진료소 선택과 실험 생존자, 야수 토벌/NPC/물자 기부를 처리합니다.
- 보상16종을 실행합니다. 야수의 포효는 같은 칸의 모든 적 목적지를 각각 선택하며 공격 보상은 복수 선택할 수 있습니다.
- 새 사냥의 보스 초기화는 현재 칸/페이즈를 유지합니다. 챕터2의 지정칸 재출현과 챕터3의 위치 보존 예외를 구분합니다.

실제 전투 구성품과 기존 저장
- 성직자 야수는 사용자 전사의 1인 체력10/8과 페이즈별5장 행동덱을 사용합니다. 보스 시트 계몽 토큰, 화기 소진, 회복의 방어2/토큰 제거/덱 섞기, 추가 행동 공개와 강제 이동을 처리합니다. 회복은 체력 치유가 아닙니다.
- 여성 야수 환자 양면과 적대 이오세프카는 참고자료 사진을 사용합니다. 여성의 두 면은 챕터에 무작위로 선택해 유지하고 이오세프카는1~2인 면(체력10)을 적용합니다. 다인 체력은 출처 자료이며 다인 실행을 지원한다는 뜻이 아닙니다.
- 루드비히의 장총은 적 진입 시 피해2/준비 카드2장, 교단의 연발총은 기본공격 방해/준비 카드1장 또는 무료 변형 준비, 화염방사기는 속도2·피해2·방해·같은 칸 다른 적 피해1/준비 카드2장을 사용합니다.
- 실제 자료는 actual-components.js, boss-components.js와 components/supplied-components.json에 전사·출처를 보관합니다. 화염방사기는 사용자가 직접 전달한 문장이 출처입니다.
- 규칙8 이하 저장은 저장 당시 임시 수치·화기 효과로 그대로 재생합니다. 실제 자료로 자동 변환하면 지난 선택 결과가 달라지므로 실제 규칙은 새 사냥에서 시작합니다.
- 별도 임시 구성물 시험4종은 기존 시험 효과를 유지합니다. 캠페인의 실제 이오세프카와 치유 시험은 서로 별개입니다.

첫 이동과 전투
- 손패 카드 선택 → 이동 → 밝은 인접 칸/출입구 선택 → 새 타일 회전·배치 → 이동 종료/추격 처리.
- 같은 칸 적과 손패 카드·빈 슬롯 선택 → 공격 → 적 행동 확인 → 필요한 회피/화기 선택 → 속도 순서대로 처리.
- 적 이동/피규어/활성화 동률은 표시된 선택에서 사냥꾼에게 가장 불리한 결과를 고릅니다.
- 임무 패널에는 이번 챕터, 현재 계몽, 공개 카드, 보유·맡긴 토큰, 적용 구성품과 출처가 표시됩니다.

유지한 기능
- 지도20종을 직접 그린 SVG로 표시합니다. 52칸·47출입구·등불7개·소모품토큰14개·출현17곳을 원본 사진과 대조했습니다.
- 지도/회전 미리보기/자료실은 같은 도식과 클릭 좌표를 사용합니다. 사진 배경/픽셀은 넣지 않습니다. 원근을 제거한 경계는 물리 치수 인증이 아닙니다.
- 중앙 등불 상호작용은 정상 등불 또는 안개 안의 아무 칸으로 순간이동합니다. 임무가 진입을 금지한 곳은 거절합니다.
- 폐가 구조와 소모품을 카드1장으로 함께 상호작용하고 적의 선행 반격을 처리합니다.
- 성배 교단 예배당의 이름 칸에서 보유품 또는 상자에서 새로 얻은 소모품을 교환합니다. 추가 스탯 비용 없이 유지1개를 얻습니다(최대3).
- 골수 가루는 자기 차례에 소진된 장착 도구/문자1장을 준비합니다. 혈석의 파편/화기는 대상이 아닙니다.
- 실제 일반 적3종6면, 장송의 칼날 양면, 스탯12장/업그레이드60장, 초대장 제외 소모품36장의 공급·꿈·초기화를 처리합니다.

현재 남은 범위
- 다른 세 캠페인, 기본판 네 사냥꾼/장치 무기, 2~4인 게임 규칙/온라인 협동은 미구현입니다.
- 제공 보상32종 중16종을 실행합니다. 나머지16종은 자료 등록 범위이며 일부는 원문 사용불가 물건입니다.
- 현재 구성품 밖의 흰 배경 기본/특수 칸 능력은 해당 원문 효과를 받은 뒤 연결합니다. 발광 공격의 일반 처리는 시험용 키워드 검증이며 현재 실제 공격 출처에는 발광이 없습니다.
- 모든 불리한 선택을 자동 계산하지 않습니다. 해당 선택은 사용자가 판단합니다.

저장
- v0.7 자동 저장은 bloodborne-hunt-v07을 사용합니다. 이전 v0.6/v0.5 자동 저장 키는 유지합니다.
- 기존 정상 v0.6 저장은 이어서 불러오며 완료 후 다음 챕터 준비를 진행할 수 있습니다. 이전 명령의 정확한 재생은 기존 규칙 분기를 유지합니다.
- v0.5 JSON은 임무 없는 실제 지도 전투 연습으로 이어집니다. 훈련 index.html/지도 검증 chapter.html은 별도 저장입니다.
- 폴더/브라우저 이동이나 캐시 삭제 전에는 JSON으로 내보내세요. 시작 소모품의 기본값 ‘없음’이 정규 시작입니다.

규칙 구현 점검표
- RULES_CHECKLIST.json/TXT/XLSX의 84행은 구현 상태·검증 근거·사용자 직접 점검을 각각 표시합니다.
- 사용자 점검은 전부 ‘미점검’입니다. 직접 확인한 행의 결과/메모만 기록하세요.
- 부분·미구현·범위 제외와 임시 전투가 있으므로 전체 규칙 완성률로 계산하지 않습니다.
- RULES_AUDIT.txt는 규칙 대조와 한계, VERIFICATION.txt는 실제 실행한 최종 검증을 기록합니다.
