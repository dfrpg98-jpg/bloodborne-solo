기준: 2026-10-12 KST

시작하기
ZIP 전체를 압축 해제하고 hunt.html을 Chrome 또는 Edge로 여세요. 인터넷이나 개발 도구 설치 없이 실행할 수 있습니다.
‘기나긴 사냥 · 챕터 1’을 선택하고 장치무기와 시작 면, 중앙 등불의 왼쪽·중앙·오른쪽 시작 칸을 고릅니다.
공개된 임무와 화면에 표시된 선택을 따라 이동·전투·탐험을 진행하세요. 도입부와 실제 공개된 임무 이야기는 게임 안에서 읽고 확대할 수 있습니다.
자세한 플레이 순서는 guide.html에 있습니다.

챕터 이어가기
임무를 완수하면 마지막 꿈에서 남은 피의 유지로 성장합니다.
‘다음 챕터 준비 · 장비 교체’에서 보관한 도구·카릴 문자·화기를 장착하거나 교체합니다. 도구와 문자는 각각 2장, 화기는 1개를 장착합니다.
중앙 등불 시작 칸과 선택한 장치무기의 면을 다시 고르면 다음 챕터를 시작할 수 있습니다.
성장한 12장 덱·소모품·보상·화기·과거 완료 카드는 보존합니다. 새 챕터의 지도·적 면/슬롯·시장·덱·트랙은 다시 준비합니다.
기나긴 사냥은 챕터 1~3을 진행하며 챕터 3 목표를 완수하면 캠페인이 끝납니다.

현재 실행 범위
한 명의 사냥꾼으로 기나긴 사냥의 번호 카드 1~60, 조건부 공개와 임무 곁가지, 후속 준비, 보스/NPC, 챕터 전환을 실행합니다.
제공된 장치무기 15종의 양면과 화기 8종을 지원합니다. 새 사냥은 현재 규칙 13을 사용합니다.
성직자 야수는 사용자 전사에 따른 1인 체력 10/8과 페이즈별 5장 행동 덱을 사용합니다. 여성 야수 환자와 이오세프카는 참고자료 카드 효과를 적용합니다.
보상 32종을 등록했고 30종은 사용 효과를 실행합니다. 작은 오르골·의식용 재료는 카드에 인쇄된 사용불가 임무 물품입니다.
이 캠페인의 실제 카드가 주는 보상 16종을 획득하며, 다른 캠페인의 보상 획득 조건을 임의로 추가하지 않습니다. 전투 연습에서는 보상 32종과 추가 실물 적 12종을 별도로 점검할 수 있습니다.
예배당 소모품 교환, 골수 가루, 안개·순간이동·초기화, 보상 장착·소진·꿈 회복을 연결했습니다. 랜턴은 현재 이동 가능한 정상 등불만 목적지로 표시합니다.
예배당 도착과 호위 완료가 겹치면 호위 완료를 먼저 처리하고 예배당 사건을 자동 판정합니다. 아직 공개되지 않은 보상·분기를 비교하는 선택 화면은 표시하지 않습니다.
다른 캠페인과 2~4인/온라인 협동은 사용자가 이후에 검토하기로 정한 범위입니다. 현재 기나긴 사냥 진행을 위해 추가로 요청하는 자료는 없습니다.

지도와 자료실
지도 20종은 직접 만든 SVG입니다. 제공된 사진을 읽어 칸·내부 연결·출입구 방향·등불·소모품·적 출현 위치를 도식으로 옮겼습니다.
구조는 52칸, 47출입구, 등불 7곳, 소모품 위치 12곳/초기 토큰 14개, 적 출현 17곳입니다. 사진 배경을 사용하지 않습니다.
촬영 원근을 제거한 경계 좌표는 전사 근사값이므로 원본 사진의 픽셀이나 물리 치수까지 같다고 주장하지 않습니다.
assets/tiles/index.html에서 지도 도식을 보고 campaign.html에서 캠페인 카드 자료, components.html에서 구성품을 확인할 수 있습니다. 자료실에는 아직 공개하지 않은 이야기와 결과도 있습니다.
원본 자료와 수신 당시 출처/임시 정책 기록은 보존했습니다. 당시의 runtime/automated 표시는 현재 구현 상태를 뜻하지 않습니다. 새 사냥의 실제 지원 범위는 실행 코드와 현재 점검표를 기준으로 합니다.
배포 ZIP에는 지도 사진 20장을 넣지 않습니다. 사용자의 원본 파일은 보존하며 다른 카드 사진은 이번 지도 교체 범위 밖입니다.
