사냥 기록

구현 범위와 저장 안내

실제 지도에서 카드 비용, 탐험, 추격, 적 활성화, 전투, 꿈의 업그레이드와 지도 초기화를 처리합니다. 적의 면과 마커 배정은 새 사냥을 시작할 때 정해지며 초기화에서는 유지합니다. 피규어는 각 종류마다 4개입니다.

캠페인 모드는 기나긴 사냥 챕터 1~3의 임무·호위·생존자 구조·특수 적·안개와 보상을 처리합니다. 공개되기 전의 카드와 뒷이야기는 표시하지 않습니다. 챕터를 완수한 뒤 꿈에서 성장하고 보관한 장비를 교체해 다음 사냥으로 이어집니다. 새 캠페인은 제공된 성직자 야수·여성 야수 환자·이오세프카의 실제 구성품을 사용합니다. 이전 저장과 별도 임시 시험은 적용 중인 임시 구성품을 표시합니다.

기본 스탯 12장, 실제 업그레이드 60장, 소모품 36장(초대장 제외)을 사용합니다. 골수 가루는 소진된 장착 보상 1장을 준비합니다. 예배당 명칭 칸에서는 소모품 1장을 피의 유지 1개로 교환합니다. 사냥꾼의 종은 다른 사냥꾼이 없는 1인용에서 사용할 수 없습니다. 새 사냥에서 제공된 장치 무기를 선택하고 양면의 슬롯·고유 효과를 사용합니다. 새 캠페인과 지도 연습의 추가 화기는 제공된 고유 효과와 재준비 비용을 사용합니다. 이전 저장과 별도 임시 구성품 시험은 저장 당시의 규칙을 유지합니다.

v0.7 사냥·v0.6 사냥·v0.5 사냥·기존 전투 훈련의 자동 저장은 각각 별도입니다. 이 화면에서 내보낸 저장은 이 화면에서 불러오세요. 새 게임을 시작하거나 브라우저 데이터를 지우기 전에는 파일로 내보내세요.

새 사냥

시작할 칸을 선택한 뒤 사냥을 시작하세요.

연습 시작 보상 선택

전투 연습에서 효과를 확인할 보상을 지급합니다. 정규 캠페인의 획득 보상이 아닙니다. 사냥 도구와 카릴 문자는 각각 2장까지 장착하며, 초과분은 시작 후 교체하거나 보관합니다.

검증 전용 시작 설정

임무와 전투의 처리 흐름을 빠르게 확인하는 모드입니다. 테스트 장비와 시작 지급을 사용하며 일반 사냥의 자동 저장은 보존합니다. 이 모드의 완주는 정규 장비로 수행한 완주 검증과 별도로 기록합니다.

검증 시작 보상 선택 · 미획득 보상 포함

개발·검증을 위한 선택 목록입니다. 소지한 보상의 장착·보관 제한은 그대로 적용합니다. 총 16장까지 지급할 수 있습니다.

검증 시작 소모품 선택

정규 소모품은 실제 덱 수량 안에서 지급합니다. 검증 소모품은 종류별 10장, 소모품 전체는 40장까지 지급할 수 있습니다.

기나긴 사냥 도입부 읽기

매 챕터 시작 시 중앙 등불 타일의 어느 칸에서 시작할지 자유롭게 정합니다. 아래 도식에서 칸을 누르거나 목록에서 선택하세요. (규칙서 10쪽)

장치 무기에 지정된 기본 화기를 대체하는 연습 설정입니다. 선택한 대체 화기를 저장에 기록합니다.

테스트 지급을 선택하면 해당 카드를 소모품 덱에서 1장 꺼냅니다. 정규 시작 지급 규칙이 아닙니다.
