블러드본 규칙 구현 점검표 v0.7.1
기준: 2026-10-11 KST
1인용 기나긴 사냥 챕터1~3, 장송의 칼날, 일반 적3종6면, 보상16종, 사용자 전사 성직자 야수와 참고자료 여성 야수 환자·이오세프카·화기3종. 구저장/별도 시험의 임시 구성품은 호환 경로로 구분합니다.

구현 상태·검증 근거·사용자 직접 점검은 별개입니다. 직접 점검은 모두 미점검입니다.
최종 테스트 실행 결과는 VERIFICATION.txt를 참고합니다. 전체 규칙 완성률을 계산하지 않습니다.

status는 구현 여부, verification은 근거 수준, manualCheck는 사용자의 직접 점검 결과입니다. 서로 같은 의미가 아닙니다.
manualCheck는 모두 미점검으로 시작합니다. 자동 테스트가 존재해도 사용자의 직접 확인을 완료로 표시하지 않습니다.
자동 테스트 근거 있음은 테스트명/파일이 존재한다는 의미입니다. 최종 버전 실행 결과는 VERIFICATION.txt를 확인합니다.
부분·미구현·범위 제외가 섞인 이 목록으로 전체 규칙 완성률/100%를 계산하지 않습니다.
페이지1/3/11/28은 표지·목차·준비 안내·제작진 페이지여서 독립 실행 조건 행으로 만들지 않았습니다. 22쪽 전투 예시는 전투 행의 근거에 포함합니다.
나머지 보상16종에는 원문 사용불가 임무 물건이 포함됩니다. 임의 사용 효과를 만들지 않습니다.
후속 임무 테스트에는 유효 상태를 조립한 분기/경계 검증도 있습니다. 실제 새 사냥부터의 전체 명령 완주 근거는 별도 행/VERIFICATION.txt로 구분합니다.
보스 초기화의 일반 위치 보존, 챕터2 카드20/22의 지정칸 재출현, 챕터3 카드42의 위치 보존은 서로 다른 조건입니다.
새 v0.7.1 사냥은 rulesVersion9의 실제 구성품을 사용합니다. 기존8/7/무버전 저장과 별도 임시 시험은 저장 당시 효과를 유지하며 저장 형식과 v07 키는 바꾸지 않습니다.
