기준: 2026-10-12 KST

이번 완료 범위
사용자가 정한 한 캠페인 우선 개발 범위에 따라 기나긴 사냥 챕터 1~3의 1인 실행을 다룬다.
다른 캠페인과 2~4인·온라인 협동은 사용자가 이후 단계로 지정하여 이번 완료 범위에서 제외한다.
현재 한 캠페인에 필요한 구성품 자료는 모두 확인했으며 추가 자료 요청은 없다.
임무와 규칙의 구현, 자연 플레이 재현, 독립 조건 검사를 구분한다. 최종 검사 수치는 VERIFICATION.txt에 기록한다.

확인한 자료
한국어 규칙서 28쪽, 기나긴 사냥 임무 카드 1~60, 지도 타일 20종과 구성품 전사를 대조했다.
참고자료 사진 42장과 안내문 1개는 SOURCE_INVENTORY.json의 파일 크기 및 SHA256과 대조했다.
장치무기 사진 28장, 적 카드 사진 10장, 화기 사진 4장과 기본 지급·수량 안내문을 확인했다.
성직자 야수와 화염방사기의 사용자 전사는 components/cleric-beast-source.txt와 supplied-components에 보존한다.
정의 JSON뿐 아니라 runtime 파일의 실제 실행도 검사한다. 카드의 반대 면 요약을 현재 면 능력에 합산하지 않는다.
공식 FAQ v1.0: https://www.cmon.com/wp-content/uploads/2023/06/Bloodborne_Boardgame_FAQ_v1.0.pdf
카드 20의 공동묘지 적갈색 출현 칸 재출현 정정과 카드 17의 별도 무작위 연결 타일 준비를 반영한다.

보상과 임무 연결
보상 32종 중 30종은 사용 효과를 실행한다. 작은 오르골과 의식용 재료 2종은 인쇄된 사용불가 임무 물품으로 보관한다.
기나긴 사냥의 임무가 주는 16종은 실제 획득 조건에 연결했다. 다른 캠페인의 획득 조건은 이후 범위다.
별도 전투 연습의 시작 보상 선택은 정규 캠페인의 임무 보상을 대신하지 않는다.
도구·문자 각각 2장 제한, 교체·보관, 합성 공격, 지속 슬롯 부착과 변형 후 재선택,
꿈에서 준비와 챕터당 1회 기록, 처치·진입·차례 시작의 실제 반응 시점을 구분한다.
임무 선택과 보상 선택이 겹칠 때 필수 장비 선택이 화면에서 가려지지 않도록 수정했다.
보관 화기도 현재 저장의 규칙에 맞는 실제 화기 정의를 표시한다.

임무 처리의 해석 경계
카드 56 공개와 카드 37의 호위 완료는 같은 예배당 이동 종료에 발생할 수 있다. 규칙서와 공식 FAQ에는 두 카드의 고유 우선순위가 없다. 새 규칙 12는 규칙서 24쪽의 가장 불리한 결과 원칙에 따라 판정한다. 28 보유·34/39 미보유로 33이 잠기는 경우는 예배당 임무를 먼저 적용한다. 나머지는 두 결과의 목표·비용·보상과 현재 자원을 보고 더 불리한 결과를 판정한다. 어느 순서든 호위 39의 유골·연발총 보상은 지급하며, 이미 해결한 56을 나중 39 획득으로 재판정하지 않는다. 이 UI는 일반 원칙에 근거한 해석이며 별도 제작사 정정이 아니다.
규칙12의 자연315명령 판정 대기와 양쪽318명령 호위 보상 결과를 실제 저장/제어기에서 대조한다. 일반 생존자 즉시 인도와 무기/도약 후속 처리는 조립 경계 회귀로도 확인한다. 조립 이력은 실제 저장 가져오기가 거절하며 자연 플레이 증거로 세지 않는다.
v0.7.4에서는 51/52의 자연 진입을 확인했고 정상 완료 경로는 미확보였다. v0.7.5에서는 원문 조건을 유지한 공개 명령만으로 두 임무의 정상 완료와 보상을 추가 확인했다. 51은 교단의 돌망치·기본 단총·시드90의 343명령으로 26을 완료하고 수혈액을 장착·사용하여 체력3/트랙8에 도달한다. 52는 야수의 발톱·기본 단총·시드90의 384명령으로 새 생존자2개를 수집·인도해 28과 사자의 선물을 장착하며 체력6/트랙8에 도달한다. 두 경로는 추가 시작 소모품이나 상태 편집을 사용하지 않는다. 각 기록은 해당 임무 완료 증거이며 그 기록 자체의 챕터3 최종 보스 승리를 주장하지 않는다. 모든 실제 제어기 결정과 매 행동 저장 가져오기 검사의 최종 실행 결과는 VERIFICATION.txt에 기록한다.

지도·저장
사진의 배경 픽셀을 사용하지 않는 독립 SVG 20종을 사용한다.
52칸·47출입구와 등불·소모품·출현 위치를 대조했으며 원근이 있는 사진 경계는 도식으로 전사했다.
픽셀·물리 치수의 동일성이나 권리 허가 판정을 인증하는 검사는 아니다.
배포본에서는 원본 지도 JPG를 제외하고 사용자의 원본 자료를 프로젝트에 보존한다.
새 사냥의 규칙은 rulesVersion 12이다. 이전 rulesVersion 11 저장의 동시 임무 순서는 보존한다. 이번 수정으로 저장 형식과 키를 바꾸지 않는다.
기존 규칙 저장은 당시 효과로 이어가며 실제 이전 저장과 독립 과거 배포 엔진의 정상 상태를 정확 복원한다.

검증 근거
RULES_CHECKLIST.json/TXT/XLSX의 같은 110항목에 구현 상태, 검증 근거, 직접 점검을 구분한다.
사용자의 직접 점검은 모두 미점검으로 남기며 자동 검사 통과를 개인 확인 결과로 기록하지 않는다.
무기 15종·양면·화기 8종의 240조합을 현행 규칙12와 보존 규칙10·11에서 각각 검사한다(총720개 전투 행렬). 모든 조합의 본편 승리를 뜻하지 않으며 규칙12의15무기 자연 본편 재생과 구분한다.
무기별 정상 본편 승리와 임무 곁가지의 자연 재현 범위는 최종 VERIFICATION.txt와 fixture manifest에서 확인한다.
독립 조건 검사에서 조립한 이력이나 상태를 자연 플레이로 재현한 결과로 계산하지 않는다.
제공 자료와 현재 한 캠페인·1인 범위의 구현을 확인하며 모든 무작위 지도·전략의 승리나 전체 보드게임의 균형을 인증하지 않는다.
