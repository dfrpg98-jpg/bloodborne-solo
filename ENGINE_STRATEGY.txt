기존 규칙 엔진과 Phaser 표시 계층 — v0.8.1
검토일: 2026-10-12

현재 규칙·저장 엔진을 유지하면서 Phaser 4.2.1을 표시 계층에 연결했습니다. 공식 npm 배포의 실행 파일과 MIT 라이선스를 assets/vendor에 포함합니다. 실행 중 CDN 다운로드가 필요하지 않습니다. Unity 또는 별도 게임 편집기의 설치는 현재 범위에 필요하지 않습니다.

책임 분리
hunt-engine.js의 create·dispatch·assertState·exportSave·importSave가 규칙, 상태, 공개 순서, 명령 기록과 저장 검증을 계속 맡습니다. 이동 준비와 첫 이동/탐험의 묶음 실행도 기존 MOVE 다음 STEP/EXPLORE 명령을 사용합니다. Phaser가 행동 가능 여부나 피해를 계산하지 않습니다.
hunt-app.js와 hunt-context.js가 지도 대상·손패·슬롯을 선택하고 공개 정보로 비용과 불가 이유를 보여 줍니다. 실제 실행은 기존 규칙 엔진에 보냅니다.
hunt-presentation.js에는 화면에 공개된 사냥꾼/적 좌표, 실제 처리된 행동 종류와 진행 번호만 전달합니다. 전체 상태, 덱, 미래 임무, 보상, 저장 데이터는 전달하지 않습니다. 직접 그린 실루엣, 이동 궤적, 베기·충격 효과와 지도 초점 표시를 구성합니다. 표시 엔진의 실패가 규칙 조작을 막지 않도록 기본 지도 버튼을 유지합니다.

이번 카메라 범위
실제 지도 위치와 스크롤은 기존 지도 화면에서 처리합니다. Phaser는 초점 효과를 제공합니다. 전체 지도를 Canvas로 이전하거나 Phaser 카메라로 확대/이동하는 작업은 이번 연결에 포함하지 않았습니다. 정식 캐릭터 스프라이트와 배경, 시각 스타일을 정하면서 카메라/연출 범위를 확장할 수 있습니다.
지도 스크롤이나 창 크기 변경을 캐릭터 이동으로 잘못 처리하지 않으며, 실제 이동된 인물만 애니메이션 대상이 됩니다. 공격 효과는 실제 처리된 공격 시점에 보여 주고 공개 전의 결과를 예고하지 않습니다. 운영체제의 동작 줄이기 설정을 따릅니다.

Phaser 선택 이유
Phaser는 JavaScript 기반의 2D 웹 게임 프레임워크입니다. 현재 규칙 코드와 브라우저 HUD를 유지하면서 장면·애니메이션·카메라 기능을 추가할 수 있습니다. 프로젝트 구조를 보고 이 표시 계층 연결을 선택했습니다. 사용한 버전과 파일 무결성·출처는 assets/vendor/phaser-provenance.json에 기록합니다.
공식 소개: https://docs.phaser.io/phaser/getting-started/what-is-phaser
Phaser 4 배포: https://phaser.io/download/phaser4
공식 npm 패키지: https://www.npmjs.com/package/phaser
Tween: https://docs.phaser.io/phaser/concepts/tweens
카메라: https://docs.phaser.io/phaser/concepts/cameras
Game: https://docs.phaser.io/api-documentation/class/game

추후 다른 클라이언트와 멀티플레이
3D 연출이나 독립 실행 파일 중심의 제작 요구가 확정된다면 Unity/Godot 이전의 제작 비용을 다시 비교할 수 있습니다. 현재 브라우저 실행과 2D 표시를 위해 규칙 전체를 다른 언어로 옮길 필요는 없습니다.
여러 사냥꾼의 규칙, 접속·방·권한, 차례와 중복 명령 처리, 동시 대응 선택, 숨은 정보의 배포, 재접속은 멀티플레이를 요청하는 후속 단계입니다. Phaser 추가만으로 이 기능들이 구현되는 것은 아닙니다. 현재 revision·명령 기록과 저장 재생 검증은 후속 개발에 활용할 기반입니다.

현재 개발 범위는 기나긴 사냥 1인용과 그 UI/UX입니다. 정식 시각 자산, 전체 지도 카메라와 연출은 이어서 개선합니다. 최종 테스트 결과는 VERIFICATION_v081.txt에서 확인합니다.


v0.8.2 적용
Phaser Sprite/Animation으로 새 투명 스프라이트 5종의 80프레임을 연결했습니다. DOM 지도와 Phaser 인물은 같은 화면 좌표로 정렬하며 hunt-camera.js가 60~180% 배율·팬·현재 위치를 관리합니다. 전체 지도 Canvas 이전 없이 기존 직접 클릭과 HUD를 유지하는 방식을 선택했습니다. 앞선 v0.8.1의 후속 계획 중 캐릭터 동작과 카메라 조작은 이번 버전에 적용했습니다. 자세한 현재 구현은 PRESENTATION_ENGINE.txt와 VERIFICATION_v082.txt를 확인하세요.
