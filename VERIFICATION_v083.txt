블러드본 솔로 v0.8.3 검증 기록
검증일: 2026-10-12

구현과 근거
장치무기 15종의 양면 외형 30개, 새 프레임 720개를 제작했다.
제공된 장치무기 사진 28장을 개별 확인했으며, 사진이 없는 장송의 칼날은 실제 게임 영상으로 보완했다.
공식 공개 이미지와 실제 플레이 영상에서 무기 구조, 잡는 손, 변형 전후 실루엣,
공격 준비·타격·회수의 대표 동작을 관찰했다. 자세한 출처와 관찰 범위는 WEAPON_REFERENCE_REVIEW.txt에 있다.
새로 그린 2D 스프라이트를 사용하며 원본 사진·게임 영상 프레임은 게임 화면과 배포본에 넣지 않는다.
원작의 모든 연계기나 3D 관절 애니메이션을 그대로 재현한 버전은 아니다.

외형과 동작 연결
정규 무기 양면의 실제 공격 슬롯 85개를 각 무기의 전용 동작에 연결했다.
대기·이동·세 공격 계열·피격·쓰러짐·변형을 표시한다. 슬롯 속도에 따라 공격 재생 속도를 조절한다.
정상 변형과 무료 변형 모두 공개된 실제 무기 면을 반영한다.
토니트루스의 전기 연출은 면 이름 대신 실제 충전 상태를 따른다.
치카게의 붉은 양손 상태, 야수의 발톱의 양손 상태는 제공된 카드의 면 순서를 따른다.
레이테르팔라슈의 수은탄 사격에는 총검 자체의 사격 자세를 사용한다.
소모품·보상 공격에 일반 무기 휘두르기를 잘못 붙이지 않는다.

자동 검사
전체 70개 테스트 파일: 2114/2114 통과, 실패 0, 건너뜀 0.
최종 영향 범위 16개 파일 재검사: 289/289 통과.
모든 30개 atlas와 720프레임이 실제 렌더러의 검증과 표시 영역 처리를 통과했다.
인접 자세가 한 프레임에 섞이던 44프레임은 Canvas GeometryMask로 표시 영역을 제한했다.
원본 생성 PNG 바이트는 변경하지 않았다. 핵심 전경 픽셀 검사에서 자기 자세 누락 0, 다른 자세 중복 포함 0이다.
스프라이트 여백 차이 때문에 변형 후 인물 크기가 급변하지 않도록 몸통 크기를 정규화했다.

실제 브라우저 확인
localhost 개발 미리보기에서 30개 외형 전부 로딩 완료와 85개 실제 공격 버튼 연결을 확인했다.
교단의 돌망치: 손패 3장 → 변형 후 2장 → 원형 복귀 후 1장, 외형 양방향 전환을 확인했다.
144% 지도 확대에서도 변형된 캐릭터와 표시 영역이 지도 위치에 맞게 보였다.
지팡이·치카게·야수의 발톱·토니트루스는 정상 변형 명령으로 만든 저장을 UI로 불러와 외형을 확인했다.
레이테르팔라슈 수은탄 사격은 실제 전투 선언·판정에서 공격 연출 1회와 피해·슬롯 점유를 확인했다.
v0.8.2 정상 전투 저장을 가져와 전투 대응 화면이 복원되는 것을 확인했다.
갤러리와 게임의 수집된 콘솔 오류·경고는 없었다.
모든 공격의 모든 프레임을 사람이 실시간으로 끝까지 관찰했다는 뜻은 아니다.

규칙과 저장
핵심 규칙 파일 4개의 SHA-256은 v0.8.2와 같다.
정상 create/dispatch 명령으로 만든 30개 무기·면 조합, 158개 저장 장면은 이전 규칙 엔진과 동일하게 재생된다.
사용자의 기존 게임 주소 저장에 검증용 진행을 쓰지 않았다. 검증은 별도 8783 주소에서 수행했다.
자동 저장 키, 저장 형식, 임무 공개 범위, 공격 비용·피해·속도는 유지한다.
미공개 임무·행동 덱·미래 보상으로 연출을 결정하지 않는다.
원본 사진 폴더와 검증 장면은 배포 제외이며, 설치 과정에서 사용자의 참고자료는 보존한다.

사용
기존 게임에서 Ctrl+F5로 새 표시 파일을 읽는다.
weapon-gallery.html에서 저장을 바꾸지 않고 모든 외형·변형·공격을 미리 볼 수 있다.
설치된 파일과 배포 ZIP의 최종 무결성 확인은 외부 최종검증-v0.8.3.json에 기록한다.
